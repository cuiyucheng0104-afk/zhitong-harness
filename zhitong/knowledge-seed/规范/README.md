# 规范

国家与浙江省的清单、计量、计价类标准的状态、编码规则与目录。

| 文件 | 内容 | 来源类型 |
|---|---|---|
| `GB50854系列标准状态与清单编码规则.md` | GB 50854-2013 与 GB/T 50854-2024 的状态、项目编码结构、补充项目编码 | 网页摘要 |
| `浙江2025清单码表说明.md` | 本库浙江 2025 清单码表的来源、编码约定与已知缺口 | 内部生成物 + 网页摘要 |
| `常用规范目录.md` | 造价工作常引用的规范、发布与实施日期、状态 | 网页摘要 |
| `清单编码/` | 浙江 2025 清单编码表（K1–K5）、国标 2013 全文（K8）、两版同码异名对照（K9） | 脚本从受控源生成 |

条目都带来源字段；`清单编码/` 里的文件由 `../_tools/kb-structured/` 生成，文件头 `> 来源` 行登记源文件与 sha256，不手改。
