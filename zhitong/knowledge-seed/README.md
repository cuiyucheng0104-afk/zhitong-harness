## 抓取说明（2026-10-19）

本批网页内容只来自 `WebSearch` 返回的摘要。`WebFetch` 对所有目标站点失败（`getaddrinfo ENOTFOUND`），沙箱出口代理对 `curl` 访问政府与标准站点返回 403，没有绕过。因此：

- 每条网页条目的 `获取方式` 写明「WebSearch 摘要」，`核验状态` 为 `待核`；摘要里的数字、日期、文号需对照条目列出的原文 URL 复核后才可用于造价文件。
- 搜不到的内容在条目的「搜不到」一节逐项写出，没有用记忆补写。
