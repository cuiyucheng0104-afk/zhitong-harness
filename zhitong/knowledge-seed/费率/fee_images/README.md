# fee_images

`image1.png`–`image16.png`：《浙江省建设工程其他费用定额（2018 版）》等来源的扫描页，公开出版物，不含客户信息。迁自旧仓 `engine-service/app/engine/data/estimate_templates/fee_images/`，与原件文件内容相同。

`image_map.json` 登记每张图对应的 WPS `DISPIMG` ID、概算模板 `5.工程建设其他费用` 的单元格（I6…I30）与费用项名称，`source` 字段是出处。转录文本在 `../fee_rules_transcription.md`。
