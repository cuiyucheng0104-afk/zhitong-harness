先在本页找与您看到的报错或现象相近的一条。报错原文通常出现在对话的工作步骤里，展开即可看到。按本页处理后仍不能解决，把报错原文（不含密钥）发给服务方。

## 安装与首次打开

### Mac 提示"无法打开"或"无法验证开发者"

安装包未经 Apple 公证，第一次打开会被拦截。在"应用程序"里按住 Control 点按应用（或右键）→"打开"→"打开"。macOS 15 及以上还需要到"系统设置 → 隐私与安全性"底部点"仍要打开"。详见[安装](/docs/install/#在-mac-上安装)。

### Mac 提示"已损坏，无法打开"

先[校验 SHA256](/docs/install/#校验安装包)。一致时，在"终端"执行：

```bash
xattr -dr com.apple.quarantine "/Applications/智通数工AI.app"
```

再右键打开。不一致时不要打开，删除后重新下载。

### Windows 提示"Windows 已保护你的电脑"

安装程序没有代码签名。点"更多信息"→"仍要运行"。

### 保存 API Key 时提示"请仅输入 API 密钥，不要包含引号、空格或环境变量赋值。"

粘贴的内容里带了引号、空格，或整行 `DEEPSEEK_API_KEY=…`。只粘贴密钥本身。

### 新会话里没有"智通数工AI"预设，或导入配置包时提示没有 zhitong-tool-tos 条目

这台电脑以前用过 DeepSeek Harness 桌面版，沿用了旧配置。完全退出应用，把 `~/.dsh/profiles/desktop` 改名（例如加后缀 `.bak`），再打开应用让它重建配置，然后重新导入配置包。原来装的第三方插件需要重装。

### 打开智通数工AI 时，出现的却是 DeepSeek Harness 的窗口（或反过来）

两个应用不能同时运行。一个在运行时打开另一个，只会把正在运行的那个调到前台。先完全退出正在运行的那个。

### 菜单里"检查更新…"提示"检查更新失败"

当前安装包没有接入在线更新服务，这个提示不影响使用。更新方法见[安装](/docs/install/#更新)。

## 配置包与存储桶

### 导入配置包时报错

每条报错的含义与处理见[导入配置包](/docs/config-package/#出错时怎么办)。报错里只有字段名，不含密钥，可以直接转发给服务方。

### 把配置包拖进对话后，它说找不到文件或要路径

导入工具需要配置包的完整路径。把路径发给它，如"导入配置包 /Users/zhang/Downloads/某某咨询.zip"。复制路径：Mac 在访达里选中文件按 `kbd:Option+Command+C`；Windows 11 右键 →"复制文件地址"，Windows 10 按住 Shift 右键 →"复制为路径"。

### 报"TOS 尚未配置（缺少 …）"或"凭据存储里没有 TOS 访问密钥"

这台电脑上还没有导入配置包，或者配置、凭据被重建或删除了。重新导入配置包。

### 访问存储桶被拒绝

现象：列目录、拉取或推送时报错，报错里通常有"拒绝访问"、`AccessDenied` 或 `403` 等字样（这是火山引擎返回的原始报错）。

可能的原因：

- 配置包里的密钥没有这个桶或这个目录前缀的权限；
- 密钥已被管理员停用或轮换；
- 只有读权限，却在推送文件。

处理：把报错原文和您要访问的路径发给贵司管理员或服务方，核对密钥权限；拿到新配置包后重新导入。

### 报"下载校验失败"或"上传后回读校验失败"

传输过程中文件不完整，或桶里的文件在传输时被别人改了。让它重试一次。上传失败时，桶里的旧版本仍在版本历史里，不会丢失。

### 报"缓存索引 … 格式不认识；删除该文件后重新拉取即可重建"

本机缓存的索引文件损坏。完全退出应用，删除报错里给出的文件（位于 `~/zhitong/.zhitong-cache/index.json`），再打开应用，让它重新拉取需要的文件。删除索引不会删除缓存里的文件。为稳妥起见，删除前先让它把要保留的本机修改推回桶。

### 拉取时结果显示冲突，文件没有更新

本机这份文件改过、还没推回桶，拉取不会覆盖它。先决定保留哪一份：要保留本机修改，就让它推回桶；要放弃本机修改，明确告诉它"放弃本机修改，用桶里的版本覆盖"。

### 推送后它说"别人在你拉取之后改过这个文件"

这次推送覆盖了同事在您拉取之后的修改。同事的版本仍在桶的版本历史里。先与同事确认保留哪一版；需要恢复时，请管理员在火山引擎控制台的版本管理中恢复。规则见[项目与存储桶目录](/docs/projects/#多人同时使用)。

### Windows 上拉取某些文件直接报错

文件名里有 `< > : " | ? *`、以点或空格结尾，或是 Windows 保留名，Windows 无法保存，工具不会自动改名。请在桶里把文件改名。

## 运行脚本

### 报 `zt_not_importable`

现象：工作步骤里某个脚本返回 `zt_not_importable`，附带一段 `message` 与 `hint`。`message` 会说明是"版本低于 3.11"、"找不到 zt 包"还是"缺少 zt 的依赖"。

原因：脚本没有用上安装包内置的 Python。

处理：

::: steps
1. 告诉它："先调用 `load_workspace_dependencies`，用它返回的 python 重新运行这个脚本。"
2. 仍然报错：完全退出应用，重新打开后再试。
3. 仍然报错：重新安装同一版本的安装包（覆盖安装不会删除您的数据），再试。
4. 仍不行：把 `message` 和 `hint` 的原文发给服务方。
:::

不要让它换用电脑上别的 Python 硬跑：按产品规则它也不会这样做。

### 每次运行脚本都弹出"请求越权执行"

脚本要在工作区文件夹之外写文件（例如写到本机缓存 `~/zhitong` 里的项目目录）时，默认的"工作区内修改"权限要求您逐次批准。确认内容是它正在做的任务后点"允许一次"。不要为了省事切换到"完全权限"。

## 资料格式

### 计价表是 `.xls`

报 `xls_unsupported`（旧版 .xls 不支持）。用 Excel 或 WPS 打开，另存为 `.xlsx`（放在原文件旁边），告诉它新文件的位置再处理；需要同事也能用时，让它把新文件推回桶。

### 报 `xlsx_unreadable`（无法读取 xlsx）

文件可能是其它软件导出、结构不规范。用 Excel 或 WPS 打开后另存为 `.xlsx` 再试。

### 只有广联达的 `.gbq`、`.gtj`、`.gcl` 文件

这些是广联达的原生工程文件，读不了。请在广联达里导出 Excel（计价表），再交给它。

### 报 `not_excel`（非 Excel 文件）

计价表只支持 `.xlsx`、`.xlsm`（`.xls` 需先另存）。Word、PDF 不能当计价表用。

### 报 `no_items`（没有读出清单行）

选的表可能不是分部分项清单与计价表。请确认表头有项目编码、名称、合价，或审核汇总表的报审、审核、核减金额列。告警码的完整说明见[结果状态与告警](/docs/results/)。

### 扫描件读不出文字

扫描件没有文字层。它会先找旁边的识别文本（`<原件名>.ocr.txt`），没有时用看图的方式读那几页。识别文本与看图得到的金额、编号，都要对照原件核对。

## 图纸

### Windows 上 DWG 打不开

Windows 用户名是中文时，转换组件不能处理中文路径下的临时目录。把用户环境变量 `TEMP`、`TMP` 改到纯英文路径（如 `C:\Temp`），完全退出并重新打开应用。仍打不开时，可以先在 CAD 软件里把图纸另存为 DXF，再交给它。

### 报 "dwg2dxf 转换失败"

图纸版本或内容转换器处理不了。在 CAD 软件里另存为 DXF 后再打开。

### 它问图纸单位，不直接算面积

图纸没有记录单位，或记录不可信时，面积、长度这类结果必须先确认单位。它会把依据（如尺寸标注比对）告诉您，请您确认是毫米、厘米、米还是英寸；比对样本足够且一致时，它也可以按比对结果自动确认，并会告诉您这是自动比对。单位未确认时，它不会自行假定单位去算面积。

### 天正图纸里有些内容读不出

天正的原生代理实体需要先在天正里导出为 T3 格式。另外，图纸空间（布局）、块内填充、线型不在读取范围内。

### 看图结果是空的

结果为空不等于图上没有：可能是图层命名不同、转换时丢失或范围不对。它会说明可能的原因；可以缩小范围或换个关键词再查。

## 结果与确认

### 结果是"资料不足"

`status:insufficient` 表示没有给出结论。看它转述的原因与提示（如缺少哪份文件、哪个参数），补齐后再运行。各状态的含义见[结果状态与告警](/docs/results/)。

### 结果是"部分完成"

`status:partial` 表示有文件、工作表或项目没有算进去。它会说明是哪些；这部分要么补齐重算，要么在使用结果时明确注明。

### 它算出的数和我手算的不一样

先看口径（合同 / 本期 / 累计）和告警：有表"没有参与"、"合计对不上"时，那部分金额没算进去。数字以脚本结果和工作底稿为准；不要让它心算一个新数来替代。仍对不上时，把工作底稿和您的计算一起发给服务方。

## 常见问题

### 它会替我算造价吗？

不会由模型算。金额与数量由脚本计算，规则和数据是普通文件，可以查看，也可以修改。模型负责阅读资料、判断、分类、摘录和写作。

### AI 给出的结果能直接用吗？

不能不经确认直接用。金额与数量一律标注"需人工确认"，报告里未核实的陈述标注"待核"。结果是供您复核的初稿，签发由人负责。

### 我们的资料会放到哪里？

放在贵司自己的火山引擎 TOS 存储桶里，由贵司持有。读取文件时，其内容会作为对话上下文发送给所配置的模型服务（默认 DeepSeek V4.1 Flash），部署方式在交付配置时说明。详见[数据与安全](/docs/security/)。

### 几个人同时用同一个项目会冲突吗？

多人共用同一个桶，桶开启版本控制，不加锁。如有覆盖，它会提示，可以回退到之前的版本。协作规则见[项目与存储桶目录](/docs/projects/#多人同时使用)。

### 扫描件和图纸能看吗？

能。扫描件优先读已有的识别文本，没有时由模型看图。DWG 图纸经转换后识别图框，按需渲染成图片供模型阅读。看图结果同样需人工确认。见 [CAD 看图](/docs/features/cad/)。

### 需要建知识库的向量索引吗？

不需要。产品不建向量库，按需读文件：先读项目说明，再读具体文件。知识库按目录组织，每个目录有说明。见[企业知识库](/docs/features/knowledge/)。

### 原来的资料怎么搬进来？

由服务方在交付前整理：按统一目录规范重排、清理重复件和系统生成物、核对文件数与总字节，再上传到桶，并出具整理报告，说明删除和改名情况。

### 能写报告以外的文书吗？

可以。函件、方案、意见书等，通过报告模板机制增加模板即可。见[报告撰写](/docs/features/report/)。
