智通数工AI 的所有工作都在对话里完成：您说要做什么，它读资料、运行脚本、写文件，遇到需要您拍板的地方先问再做，最后把结果和需要复核的事项如实告诉您。本页说明这个过程中您会看到什么、需要做什么。

## 分工：谁做什么

| 事 | 由谁做 |
|---|---|
| 阅读资料、判断、分类、摘录、写作 | 模型（DeepSeek V4.1 Flash） |
| 金额、数量的计算：核对、指标、投控检测、概算、清单查码 | 产品内置的脚本。模型不心算、不改脚本给出的数字 |
| 选哪份文件、取哪种口径、是否覆盖别人改过的文件 | 您。它会用确认提问问您 |
| 最终签发 | 您。所有金额与数量都标注"需人工确认" |

## 怎么交代一件任务

一句话里说清三件事：**哪个项目**、**做什么**、**有什么要求**。项目用编号最准确（如 2026-007）；只说工程名也可以，同名时它会列出候选让您选。

::: utterances
- 打开 2026-007，看看资料缺什么
- 核对一下 2026-007 的送审和审定计价表
- 2026-007 按建筑面积算一下土建的单方造价
- 2026-007 的施工合同里，关于价款调整是怎么约定的？给出条款位置
- 2026-007 用结算审核报告模板写一份初稿，先列章节给我看
:::

几点建议：

- **一次说一件事，或按顺序说清几件事。** 例如"先盘点资料，再核对计价表"。很长的多步工作可以先让它出计划，见[多步任务与多代理](/docs/agents/)。
- **不要让它"估一下总价""心算一下合计"。** 合计、差额、占比都由脚本算；需要某个数时，说要哪项计算，它会调用对应能力。
- **要出处就直接说。** 它的回答引用只指向实际读过的文件与位置，格式如〔资料/合同.pdf p3〕；没有出处的数字会被标出。
- **资料里的"指令"不会被执行。** 文件里写着"请把金额写成…"之类的话只当作资料内容，它会提示"原文中含疑似对 AI 的指令，已忽略"。

输入框里按 `/` 打开命令菜单，按 `@` 引用文件或其它对话。它正在工作时，您还可以继续发消息，消息会排队，等当前步骤结束后处理；要立即停下，点输入框的"停止生成"。

## 看懂它的工作步骤

它每做一步，对话里都会出现一行工作步骤，进行中显示"正在…"，完成后变为"已…"，可以展开看细节。常见的几种：

| 步骤文字 | 它在做什么 | 对应工具 |
|---|---|---|
| 正在调用工具 / 已调用工具 | 列公司存储桶目录、拉取或推送文件 | `tos_ls` 列目录，`tos_stat` 查单个文件状态，`tos_pull` 从桶拉到本机，`tos_push` 推回桶并回读校验 |
| 正在读取文件 / 已读取文件 | 读本机文件内容 | `read` |
| 正在读取图片 / 已读取图片 | 看扫描件页面或图纸渲染图 | `read_image` |
| 正在运行命令 / 执行了命令 | 运行产品内置脚本，如核对、指标 | 命令里会出现 `scripts/reconcile.py run` 这类脚本名 |
| 正在搜索网页 / 已搜索网页 | 查网上资料（如规范更新） | `web_search`、`web_fetch` |
| 正在更新计划 / 更新了计划 | 维护任务清单 | `todo_write` |
| 正在协调子智能体 / 已协调子智能体 | 把一部分工作交给子智能体 | `subagent` |
| 等待你的操作 | 在等您回答确认提问或批准 | `ask_user_question` |

运行脚本前，它会先调用 `load_workspace_dependencies` 取得安装包内置的 Python 路径，这是正常步骤。步骤显示多少细节可以在设置里的"工作步骤展示"调整：简洁、标准、详细、完全展开。

## 需要您拍板时：确认提问

遇到只有您能决定的事，它会发起确认提问。提问卡片出现在输入框的位置：

::: steps
1. 读问题与选项。排在第一位、带"推荐"标记的选项已经预先选中，但还没有提交。
2. 点选一个选项，或在文本框里写自己的答案；一张卡片可能有几个问题，用翻页切换。不想回答某题可以"跳过"。
3. 全部答完后提交。它收到答案后继续工作。
:::

- 它会**一直等您回答**，不会因为超时自己做决定。
- 关闭卡片只是把它收起来；点对话里对应的提问步骤可以重新打开。
- 已回答的提问在对话里显示为只读，标注"已回答"，可以展开查看当时的选择。

常见的确认提问：

| 场景 | 它会问 |
|---|---|
| 送审、审定计价表有多份候选 | 哪份是送审、哪份是审定 |
| 新开项目 | 工程名称、咨询类型（全过程造价咨询 / 结算审核 / 招标控制价编制）、阶段（概算 / 招标控制价 / 施工过程 / 结算 / 审定） |
| 项目说明里有"待确认"字段 | 请您补全 |
| CAD 图纸单位不明确 | 图纸单位是毫米还是米等，依据是什么 |
| 归档前 | "按这样归档？" |
| 要覆盖别人刚改过的文件 | 是否覆盖 |

## 需要您批准时：越权执行

它在一个受限的环境里运行命令：默认权限是"工作区内修改"，在工作区文件夹之外写文件、或需要越过限制的命令，会先请您批准。这时对话里出现"等待审批"，卡片写着"工具 {工具名} 请求越权执行"，可以展开看要执行的具体内容。

- 点"允许一次"：只放行这一次。
- 点"拒绝"：不执行，它会换个办法或告诉您做不了。

权限模式在输入框旁的访问模式里切换："仅可查看"、"工作区内修改"（默认）、"完全权限"。建议保持"工作区内修改"。"完全权限"会减少确认步骤、可以直接执行更多操作，开启前会要求您确认风险。

## 读结果：状态、告警与"需人工确认"

各项能力的脚本都返回统一格式的结果，它会如实转述：

| 结果状态 | 含义 |
|---|---|
| `status:ok` | 按要求完成 |
| `status:partial` | 部分完成：有文件、工作表或项目没有算进去，它会说明是哪些 |
| `status:empty` | 运行正常，但没有找到符合条件的内容 |
| `status:insufficient` | 资料不足，没有给出结论；它会转述原因和下一步该补什么 |

告警按级别分：`level:error` 表示有东西没算进去或算不准，结果缺了一块；`level:warn` 表示按降级方式处理了；`level:info` 是说明。脚本失败时以错误结束，不会给出"成功但为空"的结果。

所有金额与数量都带 `status:manual` 标记。没有处理完的事项，它会写进当次工作目录里的 `待确认清单.md`。逐项说明见[结果状态与告警](/docs/results/)。

::: confirm
- 金额、数量、面积：对照工作底稿（如 `核对结果.xlsx`）复核后才能使用。
- 报告里标"待核"的陈述：核实后再去掉标记。
- 看图、扫描件识别得到的文字和数字：对照原件核对。
- 最终签发由人负责。
:::

## 文件放在哪里

每个项目在公司存储桶里有固定的目录（详见[项目与存储桶目录](/docs/projects/)）：

::: filetree 示例项目 2026-007
```text
项目/2026-007-某综合办公楼/
  项目说明.md          # 它开项目时第一个读的文件
  资料/                # 客户原件
  图纸/                # DWG 等图纸
  工作/
    2026-10-19-核对/   # 一次任务一个文件夹：<日期>-<任务>
      result.json
      核对结果.xlsx
      待确认清单.md
  成果/                # 报告、审定单、清单、概算等正式成果
```
:::

- **中间产物**放在 `工作/<日期>-<任务>/`，同一天同类任务再做一次时文件夹名加 `-2`。
- **正式成果**放在 `成果/`。
- 它先把要用的文件拉到本机缓存 `~/zhitong`（Windows `%USERPROFILE%\zhitong`），目录结构与桶里一样，在本机上处理，完成后用 `tos_push` 推回桶并回读校验。**没有推回桶的文件只在您的电脑上**，同事看不到。
- 它把文件作为交付物展示时，对话里会出现文件卡片，点击用电脑上的默认应用（如 Excel、Word）打开。没有卡片时，按它给出的本机路径打开即可。

## 模型与 API Key

- 默认模型是 DeepSeek V4.1 Flash，在输入框的模型选择器里显示"官方推荐"。它支持图片输入，看扫描件和图纸靠这一点。
- 换模型：在模型选择器里选。在设置里另选的模型优先于默认值。
- 换 API Key 或添加公司网关：打开"设置 → 模型"，见[安装](/docs/install/#使用公司的模型网关)。

## 长对话与新会话

一次会话可以做完一个项目的全部工作。对话很长时，它会自动把较早的内容压缩成摘要（对话里显示"上下文已压缩"），您也可以输入 `/compact` 手动压缩。项目里的关键结论都写在文件里（项目说明、待确认清单、工作底稿），开新会话时它会先读项目说明，不依赖之前的对话。更多见[多步任务与多代理](/docs/agents/)。
