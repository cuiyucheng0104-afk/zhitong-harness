## 2. 目的

让访客按任务找到 12 项能力中的一项，在 10 秒内看清它要什么资料、交出什么文件、文件放在哪、有哪些限定，并从小动画看到它的真实做法（逐行配对、两路核对、占位符换值、先演练后执行）。

### 4.5 小动画舞台尺寸

```html
<figure class="feature-art" data-art="check">
  <div class="art-stage">
    <svg class="art-in"   viewBox="0 0 264 200" aria-hidden="true" focusable="false">…</svg>
    <svg class="art-link" viewBox="0 0 32 200"  aria-hidden="true" focusable="false">…</svg>
    <svg class="art-out"  viewBox="0 0 264 200" aria-hidden="true" focusable="false">…</svg>
  </div>
  <div class="art-foot"><span class="art-tag">示例</span><span class="art-progress"></span><button class="art-toggle" hidden>…</button></div>
  <figcaption class="visually-hidden">{art.caption}</figcaption>
</figure>
```

- `.feature-art`：`container: art / inline-size`；底 `#f6f9fe`，1px `#e0eaf8`，圆角 8px，内边距 12px 12px 10px（容器查询按内容盒宽度判断，所以舞台宽 = 面板内容宽 − 24px 内边距 − 2px 边框，§4.1 表中已计入）。

### 5.2 类型（`src/types/portal.ts`）

```ts
export type SceneId = 'check' | 'review' | 'cad';
export type GroupId = 'project' | 'calculate' | 'output' | 'knowledge';

  | 'project' | 'qa' | 'cad' | 'check' | 'metrics' | 'control'
  | 'estimate' | 'report' | 'bills' | 'archive' | 'knowledge' | 'cloud';
export type GlossaryKey = '公司存储桶' | '项目说明' | '案例索引' | '待确认清单' | '配置包';
export type IconName = 'folder' | 'chat' | 'cad' | 'sheet' | 'calc' | 'shield' | 'file' | 'archive' | 'team' | 'cloud';

export interface FeatureOutput {
  path: string;   // 项目内相对路径（知识库、案例索引除外），/ 分隔
  note?: string;  // 括号内备注
}

export interface Feature {
  id: FeatureId;
  skill: `zt-${string}`;          // 眉题里显示的 skill 名
  name: string;                    // 列表与文档标题
  badge?: '管理员';
  icon: IconName;
  kicker: string;                  // `${组名} · ${skill}`
  title: string;                   // h3
  description: string;
  input: string;                   // 需要什么
  output: string;                  // 得到什么
  say: readonly [string, string];  // 您可以这样说（用户原话，取自 文档内容/features-<id>.md「您可以这样说」）
  outputs: readonly FeatureOutput[];
  caution: string;
  cautionLevel: 'info' | 'warn';
  scene?: SceneId;                 // 有值才显示"查看工作示例"
  docs: `/docs/features/${FeatureId}/`;
  terms: readonly GlossaryKey[];
  home: boolean;                   // false 时不在首页出现，计数与尺寸线随之变化
  art: { caption: string; loop: number };  // loop：循环总时长（秒），§7 各节的值
}

export interface FeatureGroup {
  id: GroupId;
  label: string;
  icon: IconName;
  intro: string;
  features: readonly Feature[];
}
```

- 构建：`active` 且可见比例 ≥ 0.35（`useInView`）时第一次构建：`await loadMotion()`，`await import('./art/timelines')`，取 `builders[id]`，建 `gsap.timeline({ paused: true, repeat: -1 })`，执行构建函数，给 `.art-stage` 加 `art-live` 类，移除暂停按钮的 `hidden`。`prefers-reduced-motion: reduce` 时不构建（原因 `reduced` 常在）。

- `hover`（指针进入 `.feature-art`）与 `focus`（焦点进入 `.feature-detail`）：`tl.pause()`，`gsap.to(tl, { time: tl.labels.hold, duration: DUR.short, ease: EASE.out })` 快进或回退到终帧并停住；指针离开 `ART.hoverResume` 秒后、焦点离开后立即 `tl.play()`。
- `user`（暂停按钮，作用于全区）：同 `hover` 的停法；再按播放时 `tl.play()`。
- 进度线：`onUpdate` 把 `tl.progress()` 写到 `figure.style --art-p`。
- 布局：`ResizeObserver` 观察 `.feature-art` 内容宽，`≥ ART.splitMin` 为 `split`，否则 `sequence`；变化时记下 `p = tl.progress()`，`tl.kill()` 后按新布局重建并 `tl.progress(p)`。

## 9. 无障碍

- 页签：`role="tablist"`/`tab`/`tabpanel`，`aria-selected`、`aria-controls`、`aria-labelledby`，漫游 `tabindex`；可读名含条数（§3.2）。
- 能力项：原生 `details`/`summary`，展开状态由原生语义表达，不额外设 `role`；"管理员"标记在 `summary` 内为可读文字。
- 选中能力项时焦点留在 `summary`；面板内容紧跟其后，Tab 可直接进入。`leaving` 面板加 `inert`，不可达。
- `h3#feature-<id>-title` 带 `tabindex="-1"`，供 `selectFeature` 与深链接聚焦。
- 小动画：三个 SVG `aria-hidden="true"`、`focusable="false"`；`figcaption`（视觉隐藏）为文本等价，内容即 `art.caption`，含动画中出现的全部数字与结论。暂停按钮满足 WCAG 2.2.2：位于每段动画外框内，作用于全区，`aria-label` 随状态切换，`aria-pressed` 反映暂停状态。
- 尺寸线、计数徽标、进度线 `aria-hidden="true"`；计数"12"按 00 章 §6.7 处理。
- 术语按钮：`ZtPopover` 规则（00 章 §6.4）。
- 颜色：核增、核减、待核、缺失、待补均有文字；SVG 内文字与底色组合达到 WCAG AA。
- 触控目标：页签、`summary`、链接、暂停按钮命中区不小于 44×44px。

## 10. 性能

- 小动画时间线（12 个构建函数 + `art-kit.ts`）为一个懒加载块，gzip ≤ 14 KB；在 `#capabilities` 距视口一屏（`rootMargin: '100% 0px'`）时预取。
- 12 段 SVG 标记随预渲染 HTML 输出，合计未压缩 ≤ 60 KB。
- 同一时刻最多一条小动画时间线在运行；循环中每帧脚本耗时 ≤ 1 ms（Chrome Performance，中端笔记本）。
- 只在切换时（Flip 高度）出现布局变化；循环中没有布局与重排。
- 章节头 ScrollTrigger 两条，均为 scrub，不 pin。
