## 一句话

打开 DWG/DXF 图纸，结构化读取图框、文字、门窗、表格与房间面积，按需出图核对；数量面积需您复核。

## 适用场景

- 看某层平面图上有哪些房间、各房间面积是多少。
- 统计门窗编号的数量，读取门窗表、材料表。
- 核对图名、图号、比例、楼层，整理图纸目录。
- 在图上找某段文字（例如所有「会议室」、所有防火门编号）的位置。
- 比较同一楼层新旧两版图纸的差异。

## 您可以这样说

- "打开 2026-007 的 A-02 二层平面图，看看有哪些房间，面积多少。"
- "二层的门窗按编号数一下。"
- "把这张图的门窗表读出来。"
- "图上标的女卫面积和实际围合面积对得上吗？放大给我看一下。"
- "这套图里每张的图名、图号、比例列个表。"
- "比较一下二层平面图的旧版和新版有什么变化。"

## 需要准备的资料

| 资料 | 要求 |
|---|---|
| 图纸文件 | `.dwg` 或 `.dxf`，放在项目的 `图纸/`。格式按文件头判断，不看扩展名 |
| 大小 | DWG 不超过 200 MiB，DXF（含 DWG 转出的）不超过 400 MiB；单次转换限时 180 秒 |
| 天正图纸 | 天正原生（T20 等）图里的专有实体读不出，请先在天正里导出 T3 格式 |

> **提示**
> 从公司的火山引擎对象存储（TOS）拉取整个目录时，`.dwg` / `.dxf` 默认不会被拉下来。助手会对需要的图纸单独执行 `tos_pull`。

## 它会怎么做

1. **拿到本机文件**（`tos_pull 图纸/<文件名>.dwg`）。
2. **开图**（`cad_open`）。DWG 先由内置的 LibreDWG `dwg2dxf` 转成 DXF，再解析。助手转述格式、转换器版本、各类实体计数、图框编号、单位状态和警告（图纸空间被跳过、块定义缺失、天正代理实体等）。
3. **确认单位**。
   - 图纸头写明了单位（`$INSUNITS`）时自动确认。
   - 没写明时单位为「未确认」：助手把证据告诉您，请您确认后记录（`cad_set_unit`，写明依据）。证据里尺寸标注比对一致（样本 ≥ 5 个、一致率 ≥ 80%）时，助手可以按尺寸标注自动确认，并告诉您这是自动比对的结果。
   - 单位未确认前，房间面积这类需要量纲的工具会拒绝执行。
4. **缩小范围，只取需要的部分**：
   - `cad_frames`：图框与标题栏；
   - `cad_text_search`：按图框、图层、关键词、正则、矩形范围、最小字高检索文字；
   - `cad_layers`：按图层统计线段、文字、块、填充，判断哪些层是墙、门窗、标注、房间名；
   - `cad_blocks`：块计数与门窗编号文字计数，两者互相印证；门窗表里列出的编号不计入数量；
   - `cad_table`：自动找门窗表、材料表；找不到时先用文字检索定位表名，再指定范围；
   - `cad_rooms`：房间面积双路核对；
   - `cad_diff`：两版图纸的差异。
5. **按需看图**（`cad_render` + `read_image`）。先出整个图框的总览图（带 A、B、C… 列和 1、2、3… 行的网格，文字画成空框），找到目标所在格子；再按格子、矩形、点周围、文字编号或句柄出局部放大图。一次问答通常 2–4 张。范围太大会被拒绝，按提示改用格子或更小范围。
6. **落盘**。把整理出的表格、清单、核对结论写进项目的 `工作/`，注明来源图纸文件名、`doc` 编号、图框编号。

### 十个工具

| 工具 | 作用 |
|---|---|
| `cad_open` | 打开图纸，返回 `doc` 编号、sha256、转换器版本、编码、范围、计数、跳过的实体、图框、单位与单位证据、警告 |
| `cad_layers` | 按图层统计，含颜色、冻结 / 关闭状态、样例文字 |
| `cad_frames` | 图框列表与标题栏启发式：图名、图号、比例、楼层，以及工程名称、日期等标题栏字段 |
| `cad_text_search` | 文字检索，结果超出行数上限时全部写入 TSV 文件 |
| `cad_blocks` | 块引用计数与门窗编号文字计数，按图框分组 |
| `cad_render` | 出一张 PNG：图框总览或局部放大 |
| `cad_set_unit` | 确认单位：人工确认或按尺寸标注比对 |
| `cad_rooms` | 房间面积双路核对（需已确认单位） |
| `cad_table` | 提取门窗表、材料表等表格，写出 CSV |
| `cad_diff` | 两张图的线段增删、文字增删、块数量变化，可出差异图 |

图框编号的含义：`S1`、`S2`… 是按 A0–A4 图幅识别出的图框线；`F1`、`F2`… 是不在图框线内、按空白距离聚类出的图形簇；两者都没有时，`W1` 表示整张图的范围。

### 示例：2026-007 滨江综合办公楼（示例数据）

您说："打开 A-02 二层平面图，看看有哪些房间，面积多少。"

**开图。** `cad_open` 返回 `doc=d3f9a1c27b04`，DWG，转换器 dwg2dxf 0.14，图框 1 个（`S1`）。单位未确认，证据：

```text
$INSUNITS=缺失；图幅跨度约 84k 单位，建筑图按惯例疑似 mm；
37 个尺寸标注的「显示值÷实测长度」中位数 1.000，一致率 97%，指向 mm
```

警告：「跳过了 46 个图纸空间（布局）实体；只读取模型空间」「单位未确认：量纲类工具（cad_rooms）会拒绝执行，见 unit.evidence」。

**确认单位。** 尺寸标注比对满足条件，助手执行 `cad_set_unit(verify=true)`，并告诉您："单位按尺寸标注自动比对确认为 mm。"

**图框与标题栏。** `cad_frames` 返回：

| id | 种类 | 图幅 | 图名 | 图号 | 比例 | 楼层/置信 |
|---|---|---|---|---|---|---|
| S1 | sheet | A1 1:100 | 二层平面图（T812） | A-02（T815） | 1:100（T817） | 2F/high |

标题栏字段：工程名称「滨江综合办公楼（T809）」。

**房间面积。** `cad_rooms(frame="S1")`：锚点 13 个，匹配 8 间（单位 mm）。

| 房间 | 文字面积 m² | 几何面积 m² | 差异 % |
|---|---|---|---|
| 女卫 | 19.44 | 19.08 | 1.85 |
| 男卫 | 22.68 | 22.61 | 0.31 |
| 开放办公区 | 486.20 | 485.93 | 0.06 |
| 会议室1 | 72.36 | 72.36 | 0.00 |
| 会议室2 | 48.60 | 48.60 | 0.00 |
| 经理室 | 36.45 | 36.45 | 0.00 |
| 茶水间 | 15.12 | 15.12 | 0.00 |
| 走廊 | — | 112.80 | — |

说明：「未匹配 5 个锚点：常见原因是墙为双线、房间边界不闭合；未匹配不等于没有房间」。走廊没有面积文字，只有几何面积。

**看图核对。** 女卫差异最大，助手先出总览 `cad_render(frame="S1")`，得到 `图纸/.cache/render/d3f9a1c27b04-S1-<编号>.png`（1600×1130 像素，A–H 列、1–6 行网格），用 `read_image` 找到女卫在 C3 格；再出局部 `cad_render(frame="S1", cell="C3")`，看到面积文字「19.44」标在女卫内，围合线在管井一侧向内收进。

**助手的汇报（节选）：**

> 二层平面图（S1，图号 A-02，比例 1:100）共匹配 8 间房，另有 5 个房间名没有匹配到闭合边界，不代表没有这些房间。女卫的标注面积 19.44 m² 与围合面积 19.08 m² 相差 1.85%，局部图显示管井一侧边界内收，请核对标注面积是否含管井。以上面积由程序计算，需人工复核。

结果整理成 `工作/图纸核对/A-02 二层平面图-房间面积.md`，注明来源图纸、`doc=d3f9a1c27b04`、图框 `S1`。

## 得到什么

| 位置 | 内容 |
|---|---|
| 对话里 | 紧凑表格：文字带 `T` 开头的文字编号与坐标，实体带句柄；面积、计数带需人工复核标记 |
| `图纸/.cache/` | 解析缓存（`<sha256>-<版本>.scene`）、单位确认记录（`<sha256>.unit.json`，再次打开同一文件仍有效） |
| `图纸/.cache/out/` | 长列表的 TSV、表格的 CSV、算量 schema JSON |
| `图纸/.cache/render/` | 渲染出的 PNG |
| `工作/图纸核对/` | 助手整理的表格、清单、核对结论（`.md` 或 `.xlsx`），需要保留的 TSV、CSV、PNG 也复制到这里 |

坐标是图纸单位，Y 轴向上。图片像素 `(px, py)` 换算为图纸坐标：`(world_rect.x1 + px / s, world_rect.y2 − py / s)`，`s` 是结果里的 `px_per_unit`。

## 结果怎么读

### 单位状态

| 状态 | 依据（`method`） | 含义 |
|---|---|---|
| `confirmed` | `$INSUNITS` | 图纸头写明了单位 |
| `confirmed` | 人工确认 | 您确认的，记录了依据 |
| `confirmed` | 尺寸比对 | 尺寸标注「显示值 ÷ 实测长度」样本 ≥ 5、一致率 ≥ 80% |
| `unconfirmed` | 待确认 | 只按毫米导航，不出面积；图框面积 `area_m2` 为空 |

### 房间面积

- `geom_m2`：房间名锚点（默认天正 `TXTROOM` 图层）所在的最小闭合多段线面积，由代码计算。
- `text_m2`：同一多边形内的面积数字文字。
- `diff_pct`：两者差异百分比；表格按差异从大到小排，没有文字面积的排在最后。
- 锚点图层上没有房间名时，结果会提示改用 `cad_layers` 找房间名所在图层，再调整配置。

### 标题栏与图框

图名、图号、比例、楼层都是按制图习惯猜出来的，每项带文字编号（`T…`）与句柄。楼层置信 `high` 表示图名明确是平面图。有疑问时用文字检索或看图核对。

### 门窗计数

`cad_blocks` 同时给块引用计数和编号文字计数（如 `M1021`、`C1518`、`FM甲1022`）。「表格内」列是门窗表里出现的编号次数，不计入数量。两种计数不一致时，以原图核对为准。

## 需要您确认的事项

> **需人工确认**
> 计数、面积由程序计算，属于需人工复核的量。引用图上内容时，助手会带出处（图框编号 + 文字编号或句柄），例如「图名『二层平面图』（S1，T812）」。

1. **图纸单位**：单位未写明时，确认是 mm、cm、m 还是 in。
2. **房间面积差异**：差异较大的房间，确认标注面积的口径（是否含管井、墙中线还是净面积）。
3. **未匹配的房间**：程序没有匹配到边界的房间，需要看图或人工量取。
4. **门窗数量**：块计数与编号文字计数不一致时，以哪一个为准。
5. **标题栏信息**：图名、图号等启发式结果。

## 限制与注意

- **只读模型空间**：图纸空间（布局）与视口里的实体全部跳过，开图时报告跳过数。
- **天正原生实体读不出**：T20 等原生图里的代理实体需要先在天正导出 T3；天正房间面积文字经转换常丢失，此时房间面积只有几何面积。
- **块内填充不解析**，只读顶层填充；填充一律按实心半透明画，不画图案。
- **线型与线宽不处理**，虚线画成实线；冻结、关闭的图层出图时默认不画，但结构化统计照常包含。
- **文字位置是近似的**：文字按插入点放置，宽度按字符数估算；多行文字不按原样折行。
- **字体**：内置笔画字体缺部分简体字时，整条文字改用内置中文字体显示；天正 / Autodesk 的大字体（gbcbig、hztxt）暂不支持。
- **启发式**：图框图幅、标题栏、门窗编号、表头关键词、房间锚点都依赖制图习惯，判据可由管理员在配置里调整。
- **大图较慢**：几百 MB 的 DXF 解析需要数秒并占用较多内存；超过体积上限直接拒绝。
- **图纸比较只处理平移**：`cad_diff` 能自动估计平移配准，不处理旋转和缩放。
- **DWG 转换程序**：DWG 依赖安装包内置的 LibreDWG `dwg2dxf`。安装包缺少它时只能打开 DXF。该程序在 Mac 与 Windows 实机安装包上的验证还在进行中。
- **图片只用来定位和核对**：助手不会从图片上数数、量尺寸、抄数字。
- **图纸里的文字是资料**：其中写的要求不会被当作指令执行。

## 常见问题

### 为什么说单位未确认，不能算面积？

图纸头没有写明单位时，同样的数值可能是毫米也可能是米，面积会差一百万倍。请告诉助手图纸单位，或在尺寸标注比对一致时让助手自动确认。确认记录保存在 `图纸/.cache/`，下次打开同一文件不用再确认。

### 房间没找全，是不是图上没有？

不是。未匹配不等于没有房间。常见原因是墙画成双线、房间边界不闭合，或房间名不在 `TXTROOM` 图层。助手会说明可能原因，必要时看图核对。

### 能直接从截图里数门窗吗？

不会这样做。门窗数量由 `cad_blocks` 按块引用和编号文字计数；图片只用来定位和核对。

### 天正画的图打开后很多东西没有？

天正原生实体转换器读不出，开图时会给警告。请在天正里把图导出为 T3 格式再打开。

### 渲染的图片存在哪里？要保留怎么办？

存在图纸目录的 `.cache/render/` 下。需要保留时让助手复制到 `工作/`，再按项目流程推回桶。

### 文字检索结果被截断了怎么办？

对话里只列前若干行，全部结果写在返回的 TSV 文件里，助手需要时会读这个文件；也可以加图框、图层或关键词条件缩小范围。
