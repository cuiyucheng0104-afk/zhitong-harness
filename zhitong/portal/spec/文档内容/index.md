智通数工AI 是造价咨询公司的对话式工作台：在您自己的电脑上，用对话完成开项目、核对、指标、投控、清单、概算、报告和看图。资料留在公司自己的火山引擎对象存储（TOS）里，金额由脚本计算，结果需要您确认后才能使用。这里是它的使用说明。

## 从这里开始

第一次使用，按顺序读这四页。已经拿到安装包和配置包、只想尽快用起来，直接看[快速开始](/docs/quick-start/)。

::: steps
1. **[安装](/docs/install/)**：下载 Mac 或 Windows 安装包，核对 SHA256，完成第一次打开和模型 API Key 设置。
2. **[导入配置包](/docs/config-package/)**：把服务方交付的配置包交给它，连上公司的存储桶。
3. **[对话、确认与结果的基本用法](/docs/basics/)**：怎么说一件任务，怎么回答它的确认提问，怎么读结果和"需人工确认"。
4. **[项目与存储桶目录](/docs/projects/)**：项目编号、项目说明、工作与成果目录、案例索引，以及多人同时使用时要注意什么。
:::

## 关于这套文档

- 文档里的项目、金额和文件都是**示例数据**，统一使用虚构项目"2026-007-滨江综合办公楼"，各页的数字可以互相对上。
- "您可以这样说"下面的句子可以点击复制，粘贴到对话框里直接用；把项目编号换成您自己的即可。
- 凡是金额、数量、面积，产品都标注"需人工确认"。文档在需要您复核的地方用"需人工确认"框标出。
- 文档对应当前发布的安装包，版本见[版本与更新](/docs/releases/)。
