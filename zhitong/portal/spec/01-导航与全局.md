## 2. 顶栏状态

**目的**：首屏时顶栏不遮挡底稿背景；滚动后变紧凑并与正文分开。

**决定：不做“下滑隐藏、上滑出现”。** 理由：（1）顶栏承载当前章节与滚动进度，是长页的位置参照；（2）03、05 章的钉住区块以顶栏紧凑高 64px 为基准计算起点（`top top+=64` 或再加间距），顶栏高度与位置必须稳定；（3）文档页侧栏与子栏按 06 章 `top: 72px` 粘附，顶栏移动会留出空隙；（4）紧凑态只占 64px，在 900px 高视口里占 7%。

**状态表**

| 状态 | 条件 | 背景层 `.site-header__bg` | 底线 | 视觉高度 | 内容行 `.header-inner` | 比例尺 |
|---|---|---|---|---|---|---|
| `top` | 首页，`scrollY ≤ 4` | `transparent`，无 `backdrop-filter` | `rgba(217,228,240,0)` | 72px | `translateY(0)` | `opacity: 0` |
| `scrolled` | 首页，`scrollY > 8` | `rgba(255,255,255,0.86)` + `backdrop-filter: blur(16px) saturate(1.3)` | `1px solid var(--line)` | 64px | `translateY(-4px)` | `opacity: 1` |
| `docs` | 文档页、404 页 | 同 `scrolled` | 同 `scrolled` | 72px（≤ 767px 为 64px），不紧凑 | `translateY(0)` | `opacity: 1` |

- 4px 与 8px 之间保持原状态（滞回），避免在临界点闪动。
- 紧凑不改 `height`（00 章 §5.4 只动变换）：顶栏盒子恒为 72px，背景层 `transform: scaleY(0.8889)`（64 ÷ 72）、`transform-origin: 50% 0`；内容行上移 4px；比例尺 `translateY(-8px)`。顶栏根元素 `pointer-events: none`，`.header-inner` 与比例尺之外不接收指针，紧凑后下方 8px 透明带不挡正文点击。
- 过渡：`transform`、`background-color`、`border-color` 均 `var(--dur-short) var(--ease-out)`；`backdrop-filter` 不过渡，在 `scrolled` 时直接开启。
- 不支持 `backdrop-filter` 时（`@supports not (backdrop-filter: blur(1px))`）背景改 `rgba(255,255,255,0.97)`。
- ≤ 767px：首页同样有 `top/scrolled` 两态，但视觉高度恒为 64px（`scaleY(1)`，内容不位移）。
- 状态由 `useHeaderState()` 计算：水合时按 `window.scrollY` 立即算一次（不等 GSAP），之后首页用 ScrollTrigger（`start: 0, end: 'max'`），文档页用被动 `scroll` 监听 + `requestAnimationFrame`（文档页不加载 GSAP，见 06 章 §9.1）。状态写为根元素的 `data-state="top|scrolled|docs"`；预渲染输出 `top`（首页）或 `docs`。
- `scrollToSection` 计算偏移时用顶栏视觉高度，不用盒子高度：首页 64px（导航目标都在 8px 以下，必为紧凑态），文档页 72px（≤ 767px 均为 64px）。偏移 = 视觉高度 + 24px（00 章 §5.3）。

**验收**：见 AC-01-01 至 AC-01-04。

## 3. 当前章节跟踪与导航滑块

**目的**：滚到哪一章，顶栏对应链接就高亮；悬停时滑块吸附到指针下的链接。

**滑块**：`useHoverIndicator`（00 章 §6.2），顶栏样式为圆角浅蓝底：高 36px、圆角 18px、`background: var(--blue-tint)`、`box-shadow: inset 0 0 0 1px rgba(6,102,245,0.12)`。顶栏使用 §14.4 的 CSS 驱动方式：滑块元素铺满整个 `.desktop-nav`，由 `clip-path: inset(0 calc(100% - var(--ind-x) - var(--ind-w)) 0 var(--ind-x) round 18px)` 显示一段，`transition: clip-path var(--dur-short) var(--ease-out), opacity var(--dur-micro) var(--ease-out)`。文档在同一组内，滑块可以移到“文档”上；分隔线不是组成员，滑块从“常见问题”移到“文档”时直接跨过它。

- 指针进入或键盘聚焦某链接：滑块移到该链接。离开整组：回到当前项；没有当前项则 `opacity: 0`。
- 当前项链接文字 `var(--brand-blue)`，`aria-current="location"`（首页章节）或 `aria-current="page"`（文档）。只变颜色，不变字重，避免宽度变化。
- 链接与主按钮挂 `v-magnetic`（00 章 §6.1，链接偏移上限 6px、按钮 10px）。滑块按链接的布局位置定位，不跟磁吸偏移。只在首页启用磁吸（文档页不加载 GSAP，指令检测到 `layout !== 'home'` 时不注册）。

**章节跟踪（首页）**：改用 ScrollTrigger，删除 `App.vue` 里的 IntersectionObserver。每个导航章节一条触发器：

```ts
for (const id of ['capabilities', 'workflow', 'trust', 'faq'] as const) {
  ScrollTrigger.create({
    trigger: `#${id}`,
    start: 'top 40%',          // 章节上沿越过视口高度 40% 的阅读线
    end: 'bottom 40%',         // 章节下沿越过同一阅读线
    refreshPriority: -1,       // 在 03、05 章的钉住区块之后计算，计入 pinSpacing
    onToggle: (self) => spy.toggle(id, self.isActive),
    onRefresh: (self) => self.isActive && spy.toggle(id, true),
  });
}
```

- 阅读线在 40%：章节标题滚到视口上部五分之二处即视为进入该章。`#install` 夹在 `#trust` 与 `#faq` 之间，在它范围内没有当前项，滑块淡出。
- 点击导航链接：立即把当前项设为目标（乐观更新），并在 `scrollToSection` 返回的 Promise 完成（Lenis `onComplete`，§14.5）前锁住跟踪器，避免滑块途经中间章节时来回跳。锁最长 1.6s，到时自动解除。
- 不把当前章节写进地址栏；只有点击导航时 `history.replaceState` 写入 `#id`（现行为）。
- GSAP 加载失败：退回 IntersectionObserver，`rootMargin: '-40% 0px -60% 0px'`，语义同上。

**验收**：AC-01-05 至 AC-01-08。

## 4. 比例尺滚动进度

**目的**：用一条底稿比例尺表示读到了哪里、各章节在哪。

**布局**：`HeaderRuler.vue` 位于顶栏背景层底边内侧，全视口宽，高 8px，`aria-hidden="true"`。底线与顶栏 1px 底线重合，刻度自底线向上。

| 层 | 绘制 | 参数（≥ 768px） | 参数（≤ 767px） |
|---|---|---|---|
| 灰刻度 `.ruler-ticks` | CSS 背景，三层 | 小刻度：`repeating-linear-gradient(90deg, var(--grid-line-strong) 0 1px, transparent 1px 1%)`，高 3px；大刻度：同式周期 10%，高 6px；底线 `1px` | 小刻度周期 5%，大刻度周期 25% |
| 蓝刻度 `.ruler-fill` | 与灰刻度同构，颜色 `var(--brand-blue)`，底线 2px | `clip-path: inset(0 calc((1 - var(--p)) * 100%) 0 0)` | 同 |
| 游标 `.ruler-cursor` | 7px 宽、5px 高、尖角朝上的三角，`var(--brand-blue)` | `transform: translateX(calc(var(--px) - 3.5px))` | 同 |
| 章节标记 `.ruler-mark` | 高 8px 竖线，`left: <位置>%` | 见下 | 只画导航四章 |

- 首页章节标记：七个章节起点 `roles · problem · capabilities · workflow · trust · install · faq`。为每章建一条只用于测量的 ScrollTrigger（`trigger: '#<id>', start: 'top top+=64'`，`refreshPriority: -1`，无回调），标记位置 = `start ÷ ScrollTrigger.maxScroll(window)`，在每次 `refresh` 后重算（已计入钉住区块的 `pinSpacing`）。导航四章标记 1.5px 宽、`var(--brand-navy)`；其余三章 1px 宽、`#8aa3c2`。当前章节的标记改为 2px、`var(--brand-blue)`。
- 文档页：标记画在正文每个 H2 处，位置 = H2 文档坐标 ÷（`scrollHeight − innerHeight`），`ResizeObserver` 监听正文高度变化后重算。
- 进度 `--p`（0–1）与 `--px`（像素）写在比例尺元素上：首页由 `ScrollTrigger.create({ start: 0, end: 'max', onUpdate })` 通过 `gsap.quickSetter` 写入（Lenis 已带阻尼，不另加 scrub）；文档页由被动 `scroll` 监听在 `requestAnimationFrame` 内写入。不做过渡，进度即时跟随。
- `top` 状态不显示比例尺（`opacity: 0`，`var(--dur-short)` 淡入）。

**降级**：减少动效时照常显示（它表示状态，不是装饰动画）。`HeaderRuler` 只在客户端挂载后渲染（`v-if="mounted"`），预渲染 HTML 与无 JS 时没有比例尺。打印时隐藏。

**验收**：AC-01-09、AC-01-10。

## 5. 移动菜单

**目的**：≤ 1023px 时提供同样的去处，单手可点。

**文案**

| 元素 | 文字 |
|---|---|
| 对话框标题（视觉隐藏） | 导航菜单 |
| 关闭按钮 | `aria-label="关闭导航菜单"` |
| 链接 | 01 产品能力 / 02 使用流程 / 03 数据与复核 / 04 常见问题 |
| 文档行 | 文档；说明行“安装、配置包、12 项能力与排错” |
| 主按钮 | 获取安装包 |
| 底部说明 | `v{version} · Mac（Apple 芯片）与 Windows（x64）`（取自 `release`；某平台 `file` 为 `null` 时该平台后加“（即将发布）”） |

**布局**：`MobileMenu.vue` 是 `<dialog id="mobile-menu" class="mobile-sheet">`，经 `BaseDialog` 以 `showModal()` 打开，铺满视口（`width: 100vw; height: 100dvh; max-width: none; max-height: none; margin: 0`），白底叠 24px 底稿网格（`var(--grid-line)`，不透明度 0.5）。

- 顶部 64px 行复刻顶栏：左品牌，右关闭按钮，位置与菜单按钮完全重合（44×44），两条线由平行旋转成 ±45°（`var(--dur-short)`），看起来是菜单按钮变成了关闭按钮。
- 链接行高 64px，左右内边距 20px，底部 1px `var(--line)`：序号 13px 等宽 `var(--text-muted)` → 标签 22px/600 → 右侧 `arrow` 20px。当前章节行标签为 `var(--brand-blue)`，左侧 2px 蓝色竖条。
- 文档行与链接行之间留 16px，标签 22px/600，说明行 14px `var(--text-muted)`。
- 主按钮固定在底部：`position: sticky; bottom: 0`，上方 16px 白色渐隐，按钮全宽、高 52px，下方 `padding-bottom: max(20px, env(safe-area-inset-bottom))`；按钮下为底部说明（13px，等宽数字）。

**交互与动效**（Web Animations API，不依赖 GSAP，首页与文档页一致）

| 时机 | 目标 | 关键帧 | 时长 / 缓动 / 延迟 |
|---|---|---|---|
| 打开 | 对话框 | `clip-path: inset(0 0 100% 0)` → `inset(0 0 0 0)` | 450ms，`cubic-bezier(.65,0,.35,1)` |
| 打开 | 链接行与文档行（5 行） | `opacity 0→1`，`translateY(16px)→0` | 450ms，`cubic-bezier(.22,1,.36,1)`，第 i 行延迟 `120 + i × 70`ms，`fill: 'backwards'` |
| 打开 | 主按钮区 | `opacity 0→1` | 280ms，延迟 470ms |
| 关闭 | 对话框 | `inset(0 0 0 0)` → `inset(0 0 100% 0)` | 280ms，同 inOut 曲线；结束后 `dialog.close()` |

- 打开：`BaseDialog` 调 `lenis.stop()`（首页）并给 `body` 加 `modal-open`；关闭后 `lenis.start()`。
- 焦点：原生模态对话框使背景惰性（inert），焦点只在菜单内循环，不另写焦点陷阱；打开后焦点落在关闭按钮（DOM 中第一个可聚焦元素）；关闭后回到菜单按钮。
- 点链接：先关闭（等 `close` 事件），再 `lenis.start()`，再 `scrollToSection(id)`；文档页上为 `router.push('/#' + id)`。点“文档”：关闭后 `router.push('/docs/')`。点“获取安装包”：关闭后打开 `AcquireDialog`，其 `trigger` 设为顶栏菜单按钮，获取弹层关闭后焦点回到菜单按钮。
- Esc、点关闭按钮关闭；视口宽变为 ≥ 1024px 时立即关闭（无动画）。
- 文档页上 06 章可通过 `MobileMenu` 的具名插槽 `extra` 在文档行下方插入内容；本章不使用。

**降级**：减少动效时去掉所有关键帧，直接显示与关闭。无 JS 时菜单按钮隐藏（现 `noscript` 规则保留），顶栏不提供导航，正文锚点仍可用。

**验收**：AC-01-11 至 AC-01-14。

## 6. 文档页上的顶栏

| 项 | 首页 | 文档页 / 404 页 |

/** 服务方联系方式；空串表示未提供，该行不显示。 */

  provider: string;   // 服务方名称，如“某某数字科技有限公司”

  phone: string;      // 显示原样；tel: 链接去掉空格、括号与短横

  hours: string;      // 服务时间，如“工作日 9:00–18:00”
}
export interface SiteConfig { contact: ServiceContact }

export const siteConfig: SiteConfig = {
  contact: { provider: '', person: '', phone: '', email: '', wechat: '', hours: '' },
};

export type ContactChannel =
  | { kind: 'phone'; value: string; href: `tel:${string}` }
  | { kind: 'email'; value: string; href: `mailto:${string}` }
  | { kind: 'wechat'; value: string };

### 8.4 上线阻断

- `launchIssues` 规则：（1）没有任何可联系渠道 → “site.config.ts：contact 至少需要电话、邮箱或微信之一”；（2）任一字段含 `/待配置|待填|TODO|xxx|示例/i` → “site.config.ts：contact.{字段} 含占位文字”；（3）任一非空的电话、邮箱、微信格式不符 → “site.config.ts：contact.{字段} 格式不正确”。

- 本项列为**上线阻断项**：在 `site/README.md`“产品边界与上线前事项”写明“填写 `src/site.config.ts` 的服务方联系方式，否则 `deploy.sh` 构建失败”。

**文案**：已复制 SHA256 校验值 · 已复制校验命令 · 已复制微信号 · 已复制页面链接 · 复制失败，请手动选择文本（错误态）。

- 视觉元素用 `popover="manual"`，每次显示调用 `showPopover()`，因此即使模态对话框已打开，提示也位于顶层之上可见。视觉元素 `aria-hidden="true"`。

## 13. 页面切换（首页 ↔ 文档）

- `App.vue`：顶栏、`AcquireDialog`、`ZtToast` 在 `RouterView` 之外常驻；`RouterView` 外包 `<Transition name="page" mode="out-in" :appear="false" @after-leave="onAfterLeave" @after-enter="onAfterEnter">`，组件的 `key` 取 `route.meta.layout`（`home | docs | notfound`）。文档页之间切换不触发本过渡，由 06 章 §9.2 在 `.docs-main` 内处理。
- CSS：`.page-leave-active { transition: opacity var(--dur-micro) var(--ease-out) }`、`.page-enter-active { transition: opacity var(--dur-short) var(--ease-out), transform var(--dur-short) var(--ease-out) }`、`.page-leave-to { opacity: 0 }`、`.page-enter-from { opacity: 0; transform: translateY(8px) }`。离开 0.16s + 进入 0.28s，总计 0.44s。
- 离开首页：`HomePage` 在 `onBeforeUnmount` 中 `revert()` 自己的 `gsap.context` 与 `matchMedia`，并调用 `smooth-scroll.ts` 的 `destroy()`（06 章 §9.1）。
- `onAfterLeave`：`window.scrollTo({ top: 0, behavior: 'instant' })`（浏览器后退且有 `savedPosition` 时滚到该位置）。
- `onAfterEnter`：进入首页时等 `ScrollTrigger.refresh()` 完成；地址带 `#id` 则 `scrollToSection(id, true, true)`；进入文档页时按 06 章 §9.3 定位锚点。
- 路由 `scrollBehavior(to, from, saved)`：`to.meta.layout !== from.meta.layout` 时返回 `false`，滚动由上述钩子负责，避免与 Lenis 和过渡冲突；同为文档页时按 06 章 §9.3（锚点 `instant` 定位、前进后退恢复 `savedPosition`、其余回到页顶）。
- 切换后焦点移到新页面的 `#main`（`preventScroll: true`），并在 `#page-status` 朗读新页面标题（“已打开：{document.title}”）。
- 减少动效：`.page-*-active { transition: none }`，直接换页。
- 首次载入（预渲染页水合）不播放过渡。

验收：AC-01-31、AC-01-32。

## 14. 本章新增基础件

### 14.1 `useScrollSpy`

```ts
export function useScrollSpy<T extends string>(ids: readonly T[]): {
  active: Readonly<Ref<T | ''>>;
  toggle(id: T, on: boolean): void;   // ScrollTrigger 回调调用
  lock(id: T, ms?: number): void;     // 点击导航时乐观设置并锁定，默认 1600ms
  unlock(): void;                     // Lenis 滚动完成时调用
};
```

`toggle(id, false)` 只在 `active === id` 时清空。锁定期间 `toggle` 不改变 `active`。

### 14.2 `useToast` 与 `ZtToast.vue`

```ts
export function useToast(): {
  show(message: string, opts?: { tone?: 'ok' | 'error'; duration?: number }): void;
};
```

全站一个 `ZtToast` 实例（`App.vue` 根部）；行为见 §11。

### 14.3 `useCopy`

```ts
export function useCopy(): {
  copy(text: string, opts: { success: string; fallbackSelect?: HTMLElement }): Promise<boolean>;
};
```

顺序：`navigator.clipboard.writeText(text)` → 失败则创建屏幕外 `<textarea readonly>`、选中、`document.execCommand('copy')`（包在 `try` 中）→ 仍失败则显示错误提示“复制失败，请手动选择文本”，并用 `Range` 选中 `fallbackSelect` 的文本。成功时显示 `success` 提示。

### 14.4 `useHoverIndicator` 的 CSS 驱动方式（扩展，不改 00 章默认行为）

增加选项 `driver: 'gsap' | 'css'`（默认 `'gsap'`）。`'css'` 时组合函数只把目标位置写成底板元素上的 CSS 变量 `--ind-x`、`--ind-w`（相对组容器的像素值）与 `--ind-o`（0 或 1），由样式表的 `transition` 完成移动；时长与缓动等同 `DUR.short`、`EASE.out`（`var(--dur-short) var(--ease-out)`）。顶栏用 `'css'`，因为文档页不加载 GSAP。06 章的本页目录指示条可同样使用。

### 14.5 `scrollToSection` 返回 Promise（扩展 00 章 §5.3）

签名保持 `scrollToSection(id: string, focus = true, instant = false)`，返回值改为 `Promise<void>`：走 Lenis 时在 `lenis.scrollTo` 的 `onComplete` 中 resolve；`instant` 或退回 `window.scrollTo` 时在下一帧 resolve。现有调用方忽略返回值即可。
