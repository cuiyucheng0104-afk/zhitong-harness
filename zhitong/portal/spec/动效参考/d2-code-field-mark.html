安装与交付

装好，导入，
开始用。

支持 Mac 与 Windows，内置运行环境与 DWG 转换组件。公司专属配置包由服务方单独交付。

配置包

配置包是服务方按贵司环境整理的一个压缩文件（内含 zhitong.config.json），不随安装包分发。

  • 公司名称
  • 对象存储的地址、区域、桶名与目录前缀
  • 访问密钥（导入后存入本机凭据存储）

首次使用

首次启动先填写模型 API Key，再把配置包拖进对话，系统校验并写入本机配置。
