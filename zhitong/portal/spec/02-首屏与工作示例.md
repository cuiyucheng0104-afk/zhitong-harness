本章规定首页第一屏：首屏文案区（`section.hero`）、三场景工作示例（`#demo`）、出处弹层、三条原则条（`#principles`）。设计变量、基础件、示例项目与统一数字以 [00-总览与设计系统.md](00-总览与设计系统.md) 为准；本章只引用，不重定义。示例中的对话、工具名、脚本参数、状态、告警、文件路径按 `zhitong/skills/zt-reconcile`、`zt-tk`、`zt-cad` 的 SKILL.md 与 `zhitong/python/zt/{reconcile,tk,costsheet}`、`zhitong/plugins/tool-cad/src` 的真实输出格式编写。

### 1.5 交互与动效

**标题字级入场（全站唯一一次字级动画）。** 用 CSS 关键帧，不等 GSAP：GSAP 块是懒加载的，等它会让已显示的标题先出现再被隐藏重播。

```css
@media (prefers-reduced-motion: no-preference) {
  .hero-title .ch { display: inline-block; animation: zt-char-in .8s cubic-bezier(.16,1,.3,1) both;
                    animation-delay: calc(.1s + var(--i) * .035s); }
  .hero-dimline path { stroke-dasharray: 100; animation: zt-dimline .6s cubic-bezier(.22,1,.36,1) 1s both; }
  .hero-enter { animation: zt-fade-up .45s cubic-bezier(.22,1,.36,1) both; }
  .hero-copy > .eyebrow.hero-enter { animation-delay: 0s; }
  .hero-description.hero-enter { animation-delay: .45s; }
  .hero-actions.hero-enter { animation-delay: .55s; }
  .platform-note.hero-enter { animation-delay: .65s; }
}
@keyframes zt-char-in { from { opacity: .08; transform: translateY(.42em); } to { opacity: 1; transform: none; } }
@keyframes zt-dimline { from { stroke-dashoffset: 100; } to { stroke-dashoffset: 0; } }
@keyframes zt-fade-up { from { opacity: 0; transform: translateY(12px); } to { opacity: 1; transform: none; } }
@media print { .hero-title .ch, .hero-enter, .hero-dimline path { animation: none !important; } }
```

- 13 个字，最后一个字在 1.32 s 结束；尺寸线 1.0–1.6 s 从左向右画出。
- 字的起始不透明度是 0.08 而不是 0：首帧标题已绘制，LCP 记录在首帧，不被动画推迟（00 §9 LCP ≤ 1.8 s）。
- 这是 00 §5.5"初始隐藏态写在 `.motion-ready` 之下"的唯一例外，理由：首屏文字必须在 GSAP 块到达前出现。约束：总时长 ≤ 1.32 s；h1 不透明度始终 ≥ 0.08；打印与减少动效时无动画。

**主按钮**：`v-magnetic`（默认参数）；点击触发 `acquire`，打开获取弹层（01 章）。

**次按钮"看它怎么工作"**：`v-magnetic`（文字链接参数，偏移上限 6px）。行为按布局分两种：

| 布局 | 行为 | 图标 |
|---|---|---|
| 并排（≥ 1280）且示例窗口可见面积 ≥ 90% | 不滚动。调用 `WorkDemo.restart()`：清除 `user` 暂停（含置顶暂停），跳到场景 1 的 0 s 并播放；示例窗口外框做一次提示：`box-shadow` 从 `0 0 0 0 rgba(6,102,245,.35)` 到 `0 0 0 6px rgba(6,102,245,0)`，0.6 s，`EASE.out`；焦点移到 `#demo`（`preventScroll: true`） | `play`（三角形） |
| 其它（堆叠，或并排但示例被滚出 10% 以上） | `scrollToSection('demo')`（Lenis，1.1 s），滚动结束回调里再 `restart()`；Lenis 不可用时 `window.scrollTo` 立即跳转后 `restart()` | `down`（向下箭头） |

决定理由：并排时示例已在按钮旁边自动播放，"滚到示例"没有目标；访客点"看它怎么工作"想要的是从头看，因此改为"从场景 1 重新播放"，并用外框提示指明示例位置。堆叠时示例在下方，先滚动再重播。图标在挂载后按 `matchMedia('(min-width: 1280px)')` 切换，SSR 输出 `down`。点击后在 `#page-status` 写入"正在播放：计价表核对"。

**"配置包"说明卡**：`ZtPopover`，触发元素是平台说明里的"配置包"三个字（`<button class="term">`，虚线下划线 1px `--text-muted`，悬停变 `--brand-blue`）。

### 1.6 降级

- 减少动效：无字级动画、无尺寸线动画、无淡入；次按钮在两种布局下都只滚动/聚焦到 `#demo`，不触发播放（示例在减少动效下不自动播放，§2.8），并把示例切到场景 1 终态。
- 无 JS：标题、说明、按钮完整显示（CSS 动画不依赖 JS，结束于终态）；主按钮是 `<button>`，无 JS 时无动作——在 `<noscript>` 中于按钮下方输出一行"安装包下载见页面下方「安装与交付」"并链接 `#install`。
- 动效块加载失败：首屏不受影响（不依赖 GSAP）；磁吸不启用。

### 1.7 无障碍

- `section.hero` `aria-labelledby="hero-title"`。标题拆字后仍是同一 `h1` 内的连续文本，NVDA、VoiceOver 读作"造价咨询公司的对话式工作台"（验收时实测）。
- 次按钮 `aria-controls="demo"`，`aria-label` 见 §1.2。
- "配置包"按钮 `aria-expanded`、`aria-controls` 指向说明卡（00 §6.4）。
- 主次按钮触控高度 ≥ 48px。

#### 2.5.2 暂停原因与恢复

| 原因 | 进入 | 退出 | 提示文字 | 热区 |
|---|---|---|---|---|
| `hover` | 指针进入 `.workbench`（仅 `(hover: hover) and (pointer: fine)`） | 指针离开 0.6 s 后 | 已暂停 · 可直接操作 | 显示当前场景已出现的全部热区，主热区带文字 |
| `focus` | 焦点进入 `#demo` 内任一元素 | 焦点离开 `#demo` | 已暂停 · 可直接操作 | 同上 |
| `user`（手动） | 点击页签、热区、预览内任一按钮、出处、确认提问卡、房间行 | 指针离开窗口且 8 s 内无指针与键盘操作；恢复时从下一个场景的 0 s 开始 | 指针在内：手动模式 · 可直接操作；指针离开：{n} 秒后继续播放（每秒更新） | 同上 |
| `user` + 置顶 | 点底栏"暂停" | 只有再点"播放" | 已暂停 · 点「播放」继续 | 同上 |
| `offscreen` | `#demo` 可见比例 < 0.35 | ≥ 0.35 | 不显示 | 不变 |
| `hidden` | `document.hidden` | 页面可见 | 不显示 | 不变 |
| `dialog` | 出处弹层打开 | 弹层关闭（`user` 仍保留，开始 8 s 计时） | 不显示 | 不变 |
| `reduced` | `prefers-reduced-motion: reduce` | 用户点"播放演示" | 不显示 | 静态显示（无脉冲） |

- 暂停 = 当前场景主时间线 `pause()`，页签进度条停住；恢复 = 从原位置继续，不重播（00 §6.3）。
- 多个原因并存时，提示文字按优先级显示：置顶 > 手动 > 悬停/聚焦。
- 底栏"暂停/播放"即 `toggle()`：暂停时加入 `user` 并标记置顶，不参与 8 s 自动恢复；再次 `toggle()` 清除 `user`（含置顶标记）并从原位置继续；`hover`、`focus` 仍按各自规则生效（指针仍在窗口内时，点"播放"后在指针离开 0.6 s 后才真正继续，提示文字在此期间为"已暂停 · 可直接操作"）。
- **响应片段**：用户主动请求的内容即使在暂停中也要播放，播完停住，不推进到下一场景：① 点页签 → 该场景从 0 s 播放到 `end` 后停在停留态；② 确认提问卡提交 → 从标签 `ask:submitted` 播到 `end`；③ 预览里的决定、房间定位、视图切换 → 各自的局部动画（≤ 0.8 s）。响应片段不受 `hover`、`focus`、`user` 影响，受 `hidden`、`offscreen`、`dialog` 暂停，`reduced` 下直接跳到终态。
- 3 轮播完后停在场景 1 终态，状态 `done`，底栏按钮变为"再看一遍"，点击从场景 1 的 0 s 开始新的 3 轮。

- 热区用 `DemoHotspot`（§10.1）挂在目标元素右上角。

### 2.8 降级

- **减少动效**：不自动播放；三个场景都显示终态；页签切换直接显示终态（无滑动）；底栏按钮为"播放演示"，点击后按时间线播放当前场景，但只保留透明度过渡（0.2 s）与文字逐字出现，去掉位移、Flip、DrawSVG、放大与扫描；热区静态（无脉冲）；`DemoCursor` 不出现，确认提问卡直接显示已提交状态。
- **无 JS**：只显示场景 1 终态（预渲染）；页签可见但无动作；文字版 `<details>` 可展开，含三个场景完整内容；出处弹层不可用，`核减额` 显示为普通文本。
- **动效块加载失败**：与减少动效相同，但页签切换可用（Vue 已水合），不显示"播放演示"。

### 2.9 无障碍

- `#demo`：`role="region"`、`aria-roledescription="轮播"`、`aria-label="工作示例"`；页签 `role="tablist"`，方向键、Home、End 切换（沿用 `onTabKeydown`），切换即手动模式；面板 `role="tabpanel"`。

- 暂停/播放按钮在 Tab 顺序中位于页签之后第一个（`order` 视觉在右下角，DOM 位于页签之后），满足 WCAG 2.2.2 可快速找到。

export type HotspotId = 'reduction' | 'sheet-tabs' | 'decision' | 'anomaly-source' | 'room-list' | 'view-toggle';

/** 流式片段：字符串逐字出现；mono 片段整段出现、等宽显示；带 hotspot 的片段出现后可点 */
export type Seg = string | { t: string; mono: true; hotspot?: HotspotId };
const m = (t: string, hotspot?: HotspotId): Seg => ({ t, mono: true, ...(hotspot ? { hotspot } : {}) });

export interface ToolSpec {
  label: string;        // 中文标签
  name: string;         // 等宽原名
  args: string;         // 等宽参数摘要（窄屏省略）
  times?: number;       // 并发次数，>1 显示 ×n
  elapsed: string;      // 产品实际耗时量级
  detail: string;       // 完成后的结果行
  warnings?: string[];  // 工具返回的警告原文
}
export interface AskSpec {
  tool: 'ask_user_question';
  header: string; question: string; detail: string;
  options: { value: HitlState; label: string; description: string }[];
  reasonLabel: string; reasons: Record<HitlState, string>; submitLabel: string;
  anomalyId: string;
}
export interface OutputFile { name: string; dir: string }
export type Cue =
  | 'files' | 'probe' | 'loading' | 'summary' | 'chapters' | 'rows' | 'warnings'
  | 'tk-loading' | 'distribution' | 'focus' | 'focus-a1' | 'record'
  | 'plot' | 'unit' | 'frame' | 'rooms' | 'grid' | 'scan-s1' | 'zoom' | 'scan-e4' | 'highlight';

type Branch<T> = T | Record<HitlState, T>;
export type Step = { at: number; p: Principle } & (
  | { kind: 'compose'; text: string; dur: number }
  | { kind: 'send' }
  | { kind: 'assistant' }
  | { kind: 'tool'; run: number; tool: Branch<ToolSpec> }
  | { kind: 'say'; segs: Branch<Seg[]> }
  | { kind: 'cue'; cue: Cue }
  | { kind: 'ask'; ask: AskSpec }
  | { kind: 'cursor'; target: string; click: boolean; dur: number }
  | { kind: 'type'; target: string; text: string; dur: number }
  | { kind: 'mark'; label: 'ask:submitted' }
  | { kind: 'status'; status: 'ok'; manual: true }
  | { kind: 'files'; files: OutputFile[] }
  | { kind: 'hotspots'; ids: HotspotId[] }
);

export interface Scene {
  id: SceneId; tab: string; icon: 'sheet' | 'shield' | 'cad';
  prompt: string; steps: Step[]; end: number; hold: number;
  footnote: string; footerFile: OutputFile & { state: string };
}

export const STREAM_CPS = 36;
export const STREAM_PAUSE = 0.12;
const PUNCT = /[，。；：、！？]/g;
/** 段落时长（秒）：字数 ÷ 36 + 中文标点数 × 0.12；mono 片段计 1 字 */
export function streamDuration(segs: Seg[]): number {
  let units = 0; let pauses = 0;
  for (const s of segs) {
    if (typeof s === 'string') { units += [...s].length; pauses += s.match(PUNCT)?.length ?? 0; }
    else units += 1;
  }
  return units / STREAM_CPS + pauses * STREAM_PAUSE;
}

/** 文字版：用户原话 → 每个工具（中文标签、原名、结果行、警告）→ 回答段落 → 提问与回答 → 状态 → 产出文件 */
export function buildTranscript(scene: Scene, decision: HitlState = 'confirmed'): string {
  const pick = <T,>(b: Branch<T>): T =>
    b !== null && typeof b === 'object' && !Array.isArray(b) && 'confirmed' in b ? (b as Record<HitlState, T>)[decision] : (b as T);
  const text = (segs: Seg[]) => segs.map((x) => (typeof x === 'string' ? x : x.t)).join('');
  const out = [`示例（${scene.tab}）。用户：${scene.prompt}`];
  for (const st of scene.steps) {
    if (st.kind === 'tool') {
      const t = pick(st.tool);
      out.push(`调用 ${t.label}（${t.name}${t.times ? ` ×${t.times}` : ''}，耗时 ${t.elapsed}）：${t.detail}`
        + (t.warnings ? `；警告：${t.warnings.join('；')}` : ''));
    } else if (st.kind === 'say') out.push(`智通数工AI：${text(pick(st.segs))}`);
    else if (st.kind === 'ask') {
      const chosen = st.ask.options.find((o) => o.value === decision)!;
      out.push(`提问（ask_user_question）：${st.ask.question}。${st.ask.detail}选项：${st.ask.options.map((o) => o.label).join('、')}。`
        + `用户回答：${chosen.label}，理由：${st.ask.reasons[decision]}`);
    } else if (st.kind === 'status') out.push('状态：完成。金额与数量需人工确认。');
    else if (st.kind === 'files') out.push(`产出文件：${st.files.map((x) => x.dir + x.name).join('、')}`);
  }
  return out.join('\n');
}
