### 1.1 目的

让访客按自己的岗位找到能用的四件事，并在不离开首页的情况下看懂每件事“要什么、得什么、谁来确认”。

  yields: string;           // 得到什么

  micro: MicroKind;
  primary: { kind: 'scene'; scene: SceneId } | { kind: 'feature' };
  docs: `/docs/features/${CapabilityId}/`;
}
export interface RoleEntry {
  id: RoleId;
  name: '造价工程师' | '审核负责人' | '公司管理者';

小动画与入口的对应：资料盘点 `inventory`、送审审定核对 `reconcile`、概算编制 `extract`、报告撰写 `draft`、投控异常复核 `review`、指标偏差复核 `benchmark`、清单待核项 `codes`、看图结果核对 `plan`、归档与案例索引 `archive`、企业知识库 `entry`、接手项目问答 `answer`、火山引擎运维 `ops`。

单测（vitest）：12 个任务的 `capability` 互不相同且覆盖全部 12 个 id；`docs` 都在 06 章路由表中；`label` ≤ 8 字；`primary.kind === 'scene'` 的恰为 `check`、`control`、`cad` 三个。

### 1.5 交互与动效

#### 1.5.1 钉住模式：滚动、阻尼与吸附（≥ 1024px 且高 ≥ 640px）

**决定：钉住。** 岗位区有三段内容，钉住后访客顺着滚动就能依次看到三个岗位，不必点页签；钉住长度一个视口高，配合吸附，停在哪个岗位一目了然。

| 阶段 | 触发器 | 目标与属性 | scrub | 说明 |
|---|---|---|---|---|
| 进入 | `trigger: '#roles'`，`start: 'top bottom'`，`end: 'top top+=64'` | 右栏 `.roles-main` `y: 48 → 0` | `SCRUB.damp`（1） | 右栏比标题晚到，形成“面板拖后”的阻尼 |
| 进入 | 同上 | 公共图框与当前岗位组 `[data-draw]` `drawSVG: '0% 0%' → '0% 100%'`，`stagger: { amount: 0.3 }`，`ease: 'none'` | `SCRUB.heavy`（1.6） | 图随滚动画出 |
| 进入 | 同上 | 当前岗位组 `[data-fade]` `opacity: 0 → 1`，位于时间线 0.6–1 | `SCRUB.heavy` | 文字在线条后出现 |
| 进入 | `useReveal`（`data-reveal="heading"`） | h2 按行入场 | — | 00 章 §6.5，时间驱动 |
| 钉住 | 见下方配置 | 岗位切换（离散）、比例尺（连续） | — | — |
| 钉住 | 与钉住同起止 | 标题组 `.roles-heading` `y: 0 → -16` | `SCRUB.damp` | 停下后再追上一点 |
| 钉住 | 与钉住同起止 | 岗位图 `y: 8 → -8` | `SCRUB.heavy` | 比标题更慢 |
| 钉住 | 与钉住同起止 | 比例尺 `--rp: 0 → 1`（`ease: 'none'`） | `SCRUB.soft`（0.6） | 连续进度 |

钉住配置（通过 §3 的 `usePinnedSteps` 创建）：

```ts
ScrollTrigger.create({
  trigger: '#roles .roles-stage',
  start: 'top top+=64',
  end: () => `+=${Math.round(window.innerHeight)}`,   // 钉住 100vh
  pin: true,
  pinSpacing: true,
  anticipatePin: 1,
  invalidateOnRefresh: true,
  snap: { snapTo: [0, 0.5, 1], duration: { min: 0.2, max: 0.6 }, ease: 'power2.inOut' },
  onUpdate: (self) => {
    const i = self.progress < 0.25 ? 0 : self.progress < 0.75 ? 1 : 2;
    if (!userScrolling && i !== activeIndex.value) setRole(i, 'scroll');
  },
});
```

- 三个吸附点 0、0.5、1 对应工程师、审核负责人、管理者；切换阈值在 0.25 与 0.75（两吸附点中点）。每个岗位占 50vh 滚动距离。
- 吸附与 Lenis：ScrollTrigger 的吸附补间会直接设置滚动位置。若与 Lenis 平滑叠加出现回弹或抖动（AC-03-04 检出），改由 `usePinnedSteps` 在 ScrollTrigger 的 `scrollEnd` 事件里计算最近吸附点并调用 `lenis.scrollTo(target, { duration: clamp(|Δ| / 1000, 0.2, 0.6), easing: power2InOut })`，参数与上式等价。
- 点击页签（或方向键切换）：立即 `setRole(i, 'user')`，同时 `lenis.scrollTo(st.start + (st.end − st.start) × [0, 0.5, 1][i], { duration: 0.6, easing: power2InOut })`；滚动期间 `userScrolling = true`，`onComplete` 后置回，避免途经中间岗位时来回切换。区块尚未进入钉住范围时点页签，同样滚到对应吸附点（页签在钉住模式下就是滚动位置）。
- 比例尺 `.roles-ruler`：1px 竖基线 `var(--grid-line-strong)`；每 10%（24px）一条 4px 小刻度；0、50%、100% 三条 10px 大刻度，右侧 8px 处标“01”“02”“03”（12px 等宽）；2px 蓝线 `transform: scaleY(var(--rp))`、`transform-origin: top`；尖角朝左的 5×7px 游标位于 `translateY(calc(var(--rp) * 240px - 3.5px))`；当前岗位的大刻度与序号为 `var(--brand-blue)`。
- 离开钉住范围后（向下或向上），岗位保持在 2 或 0，不再随滚动变化。
- 窗口尺寸变化：`ScrollTrigger.refresh()` 后按新进度重算岗位，不播放切换动画。

#### 1.5.2 非钉住模式（< 1024px、矮视口、减少动效以外的其它情况）

- 页签点击或方向键切换岗位，不滚动页面。
- 入场：标题 `useReveal heading`；右栏或面板 `useReveal block`；岗位图在 `start: 'top 75%'` 时画一次（`drawSVG 0% → 100%`，`DUR.long`，`EASE.inOut`，`stagger: { amount: 0.3 }`），文字随后 `opacity 0 → 1`（`DUR.short`）。
- ≥ 768px：岗位图视差 `y: 16 → -16`，`trigger: '#roles'`，`start: 'top bottom'`，`end: 'bottom top'`，`scrub: SCRUB.soft`。≤ 767px 不做视差。
- 触屏横扫切换：`Observer.create({ target: '.role-panels', type: 'touch', tolerance: 48, lockAxis: true, onLeft: next, onRight: prev })`；只在 `(hover: none)` 下注册，首尾不循环。

### 1.6 降级

- **减少动效**：不钉住；不注册任何 scrub；岗位切换直接替换（无位移、无淡变）；岗位图直接显示终态；入口无悬停时间线，悬停只用 CSS 改颜色与显示下划线（`scaleX(1)`，无过渡）；小动画直接显示末帧；比例尺不渲染。
- **动效未加载或加载失败**：岗位图、面板、入口都是预渲染终态；页签切换用 `hidden` 属性直接切换；入口点击仍打开说明卡（`ZtPopover` 不依赖 GSAP 打开，00 章 §6.4）；小动画显示末帧（组件的静态 SVG 即末帧）。
- **无 JS**：预渲染选中工程师，其余两个面板 `hidden`；`index.html` 的 `noscript` 样式改为：`.role-panels { display: block } .role-panel[hidden] { display: block; visibility: visible } .role-panel + .role-panel { margin-top: 30px } .role-tabs { display: none }`，并删除现有 `.task-links button` 隐藏规则。入口为普通链接，直达文档页。岗位图只显示工程师组。
- **打印**：三个面板全部显示，岗位图显示当前组终态。

### 1.7 无障碍

- 页签：`role="tab"`、`aria-selected`、`aria-controls="role-panel-<id>"`，漫游 `tabindex`；方向键、Home、End 切换（沿用 `onTabKeydown`）。面板 `role="tabpanel"`、`aria-labelledby="role-tab-<id>"`。
- 钉住模式下由滚动引起的岗位变化只更新 `aria-selected` 与漫游 `tabindex`，不移动焦点，不朗读；用户点击或键盘切换时按标准页签行为。
- 入口：链接语义 + `aria-haspopup="dialog"`、`aria-expanded`、`aria-controls`；可见文字即可访问名称（“01 资料盘点”，序号在 `aria-hidden` 之外以便读出顺序）。触控目标 ≥ 44×44px。
- 说明卡：按 00 章 §6.4；小动画区 `aria-hidden="true"`，其信息已由“一句话 / 需要什么 / 得到什么”文字给出。
- 岗位图与比例尺 `aria-hidden="true"`。
- 颜色之外的区分：盘点徽标、印章、待核都带文字。

## 2. 它解决什么 `#problem`

### 2.1 目的

用一段可滚动驱动的图示说明：旧做法下一个项目要在九个功能里各点一轮、结果散落；新做法在一次对话里按需调用、结果有固定去处。

#### 2.5.3 对照列表

- 进入：两列 `useReveal stagger`。
- 连线（≥ 1024px）：连线槽 SVG 内每对“旧 i → 新 j”一条三次贝塞尔 `M0 yi C W/2 yi, W/2 yj, W yj`（`yi`、`yj` 为两条目中线，`refresh` 时计算），1px `var(--grid-line-strong)`，两端 2.5px 圆点；`drawSVG 0% → 100%`，`stagger: 0.08`，`trigger: '.compare'`，`start: 'top 75%'`，`end: 'top 35%'`，`scrub: SCRUB.soft`。
- 悬停（精确指针）旧方式条目：其连线变 `var(--brand-blue)`、1.5px，对应新方式条目底色 `var(--blue-050)`；悬停新方式条目：所有指向它的连线与旧条目同样高亮。过渡 `var(--dur-short) var(--ease-out)`。条目本身不可聚焦（不加 `tabindex`），对应关系已由“对应旧方式”文字提供。

### 2.6 降级

- **减少动效**：不钉住、不 scrub；网格显示全部点击标记、待确认菱形与“上次结果”，退出面板显示“不再单独做”，线程全部显示，计数器直接为“60–150 次点击”；对照列表连线直接画全，无悬停过渡。
- **动效未加载 / 无 JS**：同减少动效（预渲染 HTML 即此状态）。
- **打印**：同减少动效，网格与线程上下排列。

### 2.7 无障碍

- 场景容器 `role="img"`、`aria-describedby="problem-scene-desc"`，内部元素 `aria-hidden="true"`；描述文字见 §2.2。
- 计数器：可见数字随动画变化，同时有视觉隐藏的真实文本“约 60 至 150 次点击（估算值，非实测）”，动画副本 `aria-hidden`（00 章 §6.7 的做法）。
- 对照列表为两个 `<ol>`，各有 `aria-labelledby` 指向“旧方式”“新方式”小标题；“对应旧方式 01、03”在所有宽度对读屏可见。
- 钉住区内没有可聚焦元素，键盘 Tab 直接越过场景进入对照列表的链接。

## 3. 本章新增基础件：`usePinnedSteps`

把一个钉住区块分成 N 个离散步骤，滚动进度、吸附与页签点击三者同步。供岗位区使用；05 章使用流程若需要同类行为可复用。

```ts
export interface PinnedStepsOptions {
  stage: Ref<HTMLElement | null>;          // 被钉住的元素
  steps: number;                           // 步数 N（≥ 2）
  start?: string;                          // 默认 'top top+=64'
  length?: () => number;                   // 钉住长度（px），默认 () => (N − 1) × 0.5 × innerHeight
  snap?: { duration: { min: number; max: number }; ease: string }; // 默认 { min: 0.2, max: 0.6 }，'power2.inOut'
  onStep(index: number, source: 'scroll' | 'user'): void;
  onProgress?(progress: number): void;     // 每帧回调，供比例尺等连续元素使用
}
export interface PinnedSteps {
  enabled: Readonly<Ref<boolean>>;         // 当前是否处于钉住模式（matchMedia 与 motion-ready 决定）
  index: Readonly<Ref<number>>;
  goTo(index: number): Promise<void>;      // 钉住时滚到吸附点 k/(N−1)；未钉住时只调用 onStep(index, 'user')
  trigger: Readonly<Ref<ScrollTrigger | null>>;
}
export function usePinnedSteps(opts: PinnedStepsOptions): PinnedSteps;
```

- 吸附点 `k / (N − 1)`；步骤由 `Math.round(progress × (N − 1))` 得出（阈值在相邻吸附点中点）。
- `goTo` 期间忽略 `onUpdate` 产生的中间步骤，Lenis `onComplete` 后恢复。
- 在 `gsap.matchMedia()` 的条件块内创建，条件不满足或组件卸载时 `revert()`；条件变化时保留当前 `index`。
- 若吸附与 Lenis 冲突（AC-03-04），在本组合函数内部改为 `scrollEnd` + `lenis.scrollTo` 实现，调用方不变。
