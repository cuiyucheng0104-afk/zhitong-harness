# 00 总览与设计系统

智通数工AI 门户 v1.1 改版 spec 的总纲。本文件规定改版范围、站点结构、视觉与动效系统、交互基础件、示例数据和验收方式；01–07 各章与 `文档内容/` 只在此基础上展开，不另立规则。若各章与本文件冲突，以本文件为准。

## 1. 改版目标

| # | 目标 | 衡量 |
|---|---|---|
| G1 | 访客第一眼看懂"它能做什么、结果为什么可信" | 首屏 5 秒内自动演示到第一个结果；工作示例 3 个场景无需点击即可看完 |
| G2 | 让可交互的地方看得出可交互 | 每个可点元素都有悬停、按下、聚焦三种反馈；示例里的可点热区有引导标记 |
| G3 | 示例像真实产品 | 示例里的对话、工具调用、状态、告警、文件路径与产品真实行为一致（以 `zhitong/skills/*/SKILL.md` 为准） |
| G4 | 滚动和交互有统一、克制的手感 | 一套动效变量与基础件贯穿全站；平滑滚动带阻尼；悬停吸附；尊重减少动效 |

## 4. 视觉系统

### 4.1 设计概念

"工程底稿"：页面像一张被逐步填写、标注、核对的底稿。所有装饰都从底稿元素里取：浅蓝网格、尺寸线、定位十字、表格行线、清单编码、图框。不使用与造价无关的装饰（抽象渐变球、星空、霓虹、3D 人物）。动效的意义是"把东西放到它该在的位置"：对齐、吸附、连线、落格。

## 5. 动效系统

### 5.1 依赖

| 包 | 版本 | 用途 | 加载方式 |
|---|---|---|---|
| `gsap` | 保持 3.13.0（或升级后锁定精确版本） | 时间线；插件 ScrollTrigger、SplitText、Flip、DrawSVGPlugin、MotionPathPlugin、CustomEase、Observer | 首屏渲染后动态 `import()`，现有 `lib/motion.ts` 机制 |
| `lenis` | 1.3.x，锁定精确版本 | 平滑滚动（阻尼） | 与 GSAP 同一懒加载块 |
| `@floating-ui/dom` | 1.x，锁定精确版本 | 说明卡定位 | 首次打开说明卡时加载 |
| `vue-router` | 4.x，锁定精确版本 | 文档子站路由 | 主包 |

GSAP 自 3.13 起全部插件随 npm 包 `gsap` 免费提供（含 SplitText、DrawSVG、MorphSVG）。不引入其它动画库。是否引入 Three.js 由 07 章决定，全站最多一个 WebGL 场景，且必须懒加载。

内容安全策略（nginx 现配置）：`script-src 'self'`、`font-src 'self'`、`img-src 'self' data:`、`connect-src 'self'`。因此不得使用 CDN、内联 `<script>`、`eval`/`new Function`、远程字体；Web Worker 只能加载同源文件；`style` 内联可以。

### 5.2 动效变量（`lib/motion-tokens.ts`）

```ts
export const DUR = { micro: 0.16, short: 0.28, base: 0.45, long: 0.8, scene: 1.2 } as const;
export const EASE = {
  out: 'power3.out',        // 入场、展开
  inOut: 'power2.inOut',    // 场景切换、位移
  expo: 'expo.out',         // 大标题、数字落定
  snapBack: 'elastic.out(1, 0.45)', // 磁吸回弹
  linear: 'none',           // 进度条、滚动驱动
} as const;
export const STAGGER = { tight: 0.04, base: 0.07, loose: 0.12 } as const;
export const SCRUB = { soft: 0.6, damp: 1, heavy: 1.6 } as const; // ScrollTrigger scrub 追赶秒数
```

CSS 侧同名变量：`--dur-micro: 160ms; --dur-short: 280ms; --dur-base: 450ms; --ease-out: cubic-bezier(.22,1,.36,1); --ease-in-out: cubic-bezier(.65,0,.35,1);`，用于不经 GSAP 的悬停与按下过渡。

### 5.3 平滑滚动（阻尼手感）

- `smooth-scroll.ts` 创建一个 Lenis 实例：`lerp: 0.085`、`wheelMultiplier: 0.9`、`smoothWheel: true`、`syncTouch: false`（触屏保留原生惯性）、`anchors: false`（锚点由 `scrollToSection` 统一处理）。
- 与 ScrollTrigger 同步：`lenis.on('scroll', ScrollTrigger.update)`；`gsap.ticker.add((t) => lenis.raf(t * 1000))`；`gsap.ticker.lagSmoothing(0)`。
- `scrollToSection(id)` 改为 `lenis.scrollTo(target, { offset: -(顶栏高度 + 24), duration: 1.1, easing: t => 1 - Math.pow(1 - t, 4) })`；Lenis 未就绪或减少动效时退回 `window.scrollTo`（`behavior: 'instant'`）。删除 `html { scroll-behavior: smooth }`，避免两套平滑叠加。
- 打开任意 `<dialog>` 或说明卡底部弹层时 `lenis.stop()`，关闭后 `lenis.start()`；可滚动的内部容器加 `data-lenis-prevent`。
- 章节内的视差与跟随一律用 `scrub: SCRUB.soft | SCRUB.damp`，形成"滚动停下后元素再追上一点"的阻尼感；位移幅度不超过 48px，避免眩晕。
- 减少动效：不创建 Lenis，scrub 改为直接定格在终态。

### 5.4 动效原则

1. 每个动画都回答"东西从哪来、到哪去"：入场从其逻辑来源方向进入（表格行从上往下落格，连线从数字指向出处）。
2. 一屏同时运动的视觉焦点不超过 2 个。装饰动效不得与示例或文案争焦点。
3. 进入可视区才播放，离开即暂停（§6.8）；页面不可见时全部暂停。
4. 只动 `transform`、`opacity`、`clip-path`、SVG `stroke-dashoffset`；不动布局属性。必要的高度变化用 Flip。
5. 任何动画都不能阻挡内容：动效未加载、加载失败或减少动效时，内容完整可读、可操作。
6. 首屏可交互前不运行装饰动效（等 `requestIdleCallback` 或 1.5 s 后再启动）。

### 5.5 无 JS 与"内容先可见"

预渲染 HTML 里所有内容处于终态（可见）。只有在 `<html>` 上加了 `motion-ready` 类（GSAP 加载成功且未减少动效）之后，入场动画才把元素设为初始隐藏态再播放。CSS 中的初始隐藏态一律写在 `.motion-ready` 之下。现版本存在"整页截图或打印时下半页标题不可见"的问题，原因是入场动画依赖滚动触发；改版后加 `@media print { .motion-ready [data-reveal] { opacity: 1 !important; transform: none !important; } }`，并且对加载时已在视口上方的元素直接置为终态。

### 5.6 减少动效

`prefers-reduced-motion: reduce` 时：不启用 Lenis；入场动画改为 0.2 s 透明度淡入或直接终态；自动轮播默认不启动，显示第一场景终态与"播放演示"按钮；装饰动效显示静态终帧；磁吸、光斑、视差关闭；数字滚动直接显示终值。

## 6. 交互基础件

各章引用下列名称，不重复定义参数。

### 6.1 磁吸 `v-magnetic`

- 适用：主按钮、次按钮、顶栏链接、页签、岗位任务入口、卡片上的"查看示例"。
- 仅在 `(hover: hover) and (pointer: fine)` 下启用。
- 感应区：元素包围盒向外扩 `radius`（默认 24px）。指针在感应区内时，元素整体向指针偏移 `(dx, dy) × strength`（默认 0.32），内部文字与图标再偏移 `× labelStrength`（默认 0.16），形成两层视差。用 `gsap.quickTo(el, 'x' | 'y', { duration: 0.35, ease: 'power3.out' })`。
- 离开感应区：回到 0，`duration: 0.6, ease: EASE.snapBack`。
- 偏移上限 10px（按钮）/ 6px（文字链接）。按下时 `scale: 0.97`，0.12 s。
- 不改变元素的命中区域与焦点环位置以外的布局。

### 6.2 滑块吸附 `useHoverIndicator`

- 适用：顶栏导航、示例场景页签、能力分组页签、岗位页签。
- 一组链接共用一个绝对定位的底板（顶栏为圆角浅蓝底，页签为 2px 下划线）。指针进入某项时，底板以 `DUR.short`、`EASE.out` 移动并伸缩到该项的位置与宽度；离开整组时回到当前选中项（没有选中项则淡出）。
- 键盘聚焦与指针悬停同等对待。
- 选中项变化时底板跟随，用同一过渡。

### 6.3 自动轮播 `useAutoplay`

用于首屏工作示例，也供 04 章能力小动画复用。

```ts
type PauseReason = 'hover' | 'focus' | 'offscreen' | 'hidden' | 'user' | 'reduced' | 'dialog';
interface Autoplay {
  index: Ref<number>;        // 当前场景
  progress: Ref<number>;     // 0..1，当前场景已播放比例，驱动页签进度条
  playing: ComputedRef<boolean>; // pauseReasons 为空
  pause(reason: PauseReason): void;
  resume(reason: PauseReason): void;
  goTo(i: number, opts?: { user?: boolean }): void;
  toggle(): void;             // 播放/暂停按钮
}
```

- 每个场景由一条 GSAP 时间线驱动，场景时长等于时间线时长加 `hold`（结果停留，默认 3.2 s）。`progress` 取 `(时间线进度 × 时长 + 已停留) / 总时长`。
- 暂停 = 时间线 `pause()`，进度条停住；恢复 = 从原位置继续，不重播。
- `hover`：指针进入示例窗口暂停，离开 600 ms 后恢复。`focus`：焦点在示例内暂停，焦点离开后恢复。`offscreen`：可见面积 < 35% 暂停。`hidden`：`document.hidden`。`dialog`：出处弹层打开时。`user`：用户点了页签、热区或任何示例内按钮，进入"手动模式"，在指针离开示例且 8 s 无操作后才恢复，从下一个场景开始。`reduced`：减少动效，见 §5.6。
- 必须有可见的"暂停 / 播放"按钮（WCAG 2.2.2），位于示例窗口右下角，`aria-label` 随状态切换为"暂停演示 / 播放演示"。

### 6.4 说明卡 `ZtPopover`

- 用于：岗位任务入口、能力卡中的术语、文档中的术语提示。
- 桌面：原生 `popover="auto"` 进入顶层，`@floating-ui/dom` 的 `computePosition` 定位（`placement: 'bottom-start'`，中间件 `offset(10)`、`flip()`、`shift({ padding: 16 })`、`arrow()`）。开：从触发元素方向 `y: 6 → 0`、`scale: 0.98 → 1`、`opacity`，`DUR.short`，`EASE.out`；内容行 `stagger: STAGGER.tight`。关：`DUR.micro` 淡出。
- 手机（≤ 767px）：改为底部弹层（复用 `BaseDialog`，从底部滑入，`DUR.base`），带拖拽把手，下拉 80px 以上关闭。
- 触发元素 `aria-expanded`、`aria-controls`；说明卡 `role="dialog"`、`aria-labelledby`；Esc 关闭，焦点回到触发元素；点击外部关闭；同一时间只开一个。
- 说明卡标准结构：标题、一句话说明、"需要什么 / 得到什么"两行、可选的 160×96 小动画区、底部动作（"看示例"跳到首屏对应场景并暂停轮播；"读文档"跳到对应文档页）。

### 6.5 入场 `useReveal`

用 `data-reveal` 标注，三种：

| 值 | 用于 | 动画 |
|---|---|---|
| `heading` | h2、首屏 h1 | SplitText 按行拆分，`mask: 'lines'`；每行 `yPercent: 100 → 0`，`DUR.long`，`EASE.expo`，`stagger: STAGGER.base` |
| `block` | 段落、卡片 | `y: 24 → 0`、`opacity: 0 → 1`，`DUR.base`，`EASE.out` |
| `stagger` | 列表容器 | 直接子元素依次 `block` 动画，`stagger: STAGGER.base` |

触发：`start: 'top 85%'`，`once: true`。中文标题按行拆，不按字拆（字级动画只用于 02 章首屏标题一次）。SplitText 使用 `autoSplit: true` 以应对字体加载与换行变化。

### 6.6 光斑 `useSpotlight`

卡片悬停时在卡片内显示跟随指针的径向高光：`radial-gradient(240px circle at var(--mx) var(--my), rgba(6,102,245,.08), transparent 60%)`，配合 1px 边框高光 `rgba(6,102,245,.35)`。用 `pointermove` 更新 CSS 变量，`requestAnimationFrame` 节流。仅精确指针启用。

### 6.7 数字滚动 `useCountUp`

金额、比例、计数进入视口时从 0（或给定起点）滚到终值，`DUR.long`，`EASE.expo`，按 `formatMoney` 实时格式化，等宽字体防抖动。元素的文本节点在预渲染时就是终值；动画期间给元素加 `aria-hidden` 的副本显示滚动值，真实值节点对读屏保持终值。

### 6.8 可见性 `useInView`

统一的 IntersectionObserver 封装：进入（可见比例 ≥ `threshold`，默认 0.35）时 `play()`，离开时 `pause()`；监听 `visibilitychange`。所有循环动画（能力小动画、装饰动效）必须挂在它上面。

### 6.9 流式文字 `ZtStream`

模拟模型输出：按字符逐段出现，速度 28–36 字/秒，遇标点停 120 ms；末尾显示 2px 闪烁光标，结束后光标淡出。读屏只读完整文本（容器 `aria-live="off"`，完成后整段写入）。可被 `useAutoplay` 暂停。

## 7. 文案规则

1. 文案以 `zhitong/portal/门户文案.txt` 为底稿，以 `zhitong/skills/*/SKILL.md` 与 `zhitong/README.md` 为事实来源；二者不一致时以 SKILL.md 为准。
2. 不夸大：不说"自动算造价""AI 审定""一键出报告"；金额数量始终带"需人工确认"；`估算值，非实测` 一类限定必须保留。
3. 数据签核状态如实：资料清单与分类规则、投控阈值、知识库条目目前未经客户签核（见 `zhitong/STATUS.md`「数据签核与口径」）。页面上不得写"按客户确认的清单""行业标准阈值"。
4. 写"您"，不写"你"（示例对话里用户的气泡除外）；中文与英文、数字之间不加空格以外的特殊处理沿用现站；数字千分位，金额两位小数，单位"元""m²"。
5. 术语首次出现时在页面上给解释：TOS 写作"公司的火山引擎对象存储（TOS）"，之后可写"公司存储桶"；"配置包"首次出现时解释它包含什么。
6. 按钮文案用动词开头，不超过 8 个字。主按钮统一为"获取安装包"（原"获取安装与配置包"过长；配置包在弹层与安装区说明）。

## 10. 无障碍

- 键盘：所有交互可用 Tab 到达；页签方向键、Home/End；说明卡与弹层 Esc 关闭、焦点归还。
- 读屏：动画中的元素不读出中间态；自动轮播区域 `aria-roledescription="轮播"`，场景切换不自动朗读（`aria-live="off"`），用户手动切换时朗读场景名。
- 聚焦环统一 `--focus-ring`，磁吸偏移时聚焦环随元素移动。
- 触控目标 ≥ 44×44px。
- 颜色不作为唯一信息（核增、核减、异常都有文字）。

## 11. 章节写作模板（01–05 章每个区块按此组织）

1. **目的**：一句话。
2. **文案**：最终稿，逐字给出，含按钮、标签、`aria-label`、空状态。
3. **布局**：桌面 / 平板 / 手机，尺寸与栅格列数。
4. **组件与数据**：文件名、props、数据结构、完整示例数据。
5. **交互与动效**：触发 → 时间线（目标、属性、起止值、时长、缓动、错开、位置参数），状态机。
6. **降级**：减少动效、无 JS、动效加载失败。
7. **无障碍**：角色、标签、键盘、朗读。
8. **验收标准**：编号 `AC-<章>-<序>`，每条可测试。
