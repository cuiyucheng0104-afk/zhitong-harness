# 计价表链路告警码

由 `zt.costsheet.warning_codes.COSTSHEET_WARNING_CODES` 生成（`tests/costsheet/test_skill_docs.py` 校验两边一致）。zt-reconcile、zt-indicator、zt-tk 共用。

级别：`error` 有东西没算进去或算不准，必须告诉用户结果缺了哪块；`warn` 按降级方式处理了，要告诉用户；`info` 说明性，可合并成一句。

`hint` 里的旧界面说法对照：「对比口径」= `--basis`；「指标计算」对话框里的总建筑面积 = `--gross-area`；「含税总造价」= `--total-amount`；「重新选择 / 分别选择文件」= 换 `--submitted` / `--approved` / `--files` 的文件。

| 码 | 级别 | 含义 | 下一步 |
|---|---|---|---|
| `not_excel` | error | 非 Excel 文件 | 计价表只支持 .xlsx / .xlsm / .xls；请不要选 Word、PDF 等文件 |
| `xls_unsupported` | error | 旧版 .xls 不支持 | 请用 Excel/WPS 把文件另存为 .xlsx 后再试 |
| `xlsx_unreadable` | error | 无法读取 xlsx | 请用 Excel/WPS 另存为 .xlsx 后再上传 |
| `stylesheet_patched` | info | 样式表已补名 | 单元格样式缺名称，已在内存里补名后读取，数据不受影响 |
| `stylesheet_dropped` | warn | 样式表已忽略 | 样式表损坏，已忽略样式读取；日期列可能显示为数字 |
| `no_items` | error | 没有读出清单行 | 请确认选的是分部分项清单与计价表（表头有项目编码、名称、合价），或审核汇总表（表头有报审、审核、核减金额） |
| `file_unpriced` | error | 无单价/金额 | 疑似招标工程量清单（只有工程量），已剔除，不参与金额计算 |
| `sheet_truncated` | warn | 工作表超长已截断 | 单表超过 8000 行，只取前 8000 行 |
| `sheet_skipped_has_items` | error | 有清单的表被跳过 | 该表含清单编码或标题像计价表，但表头没认出来 / 口径有歧义，其金额未计入 |
| `sheets_skipped_by_title` | info | 按标题跳过的表 | 封面、说明、费用表、工日/台班/材料一览表等非清单表不计入 |
| `measure_sheets_skipped` | warn | 技术措施表没有参与 | 施工技术措施项目综合单价计算表按所选口径读不出或版式认不出，这些措施项没有参与；措施项目上的问题请人工核对 |
| `sheets_skipped_non_list` | info | 非国标清单表已排除 | 国标编码行不到一半的表（如万元估算表）不参与指标计算 |
| `column_ambiguous` | error | 金额列口径有歧义 | 表头有多组金额/工程量列，无法确定取哪一组；请在「对比口径」里选择合同 / 本期 / 累计 |
| `basis_not_found` | error | 表头没有所选口径的金额列 | 这张表没有所选口径的金额列。请把对比口径改为『自动』 |
| `party_columns_missing` | warn | 没有对应当事方的列 | 表头分了送审/审核列，但没有本侧要的那一组，已按不带当事方的列取数 |
| `amount_scaled_wan` | info | 万元已换算为元 | 表头标注「万元」，金额与单价已乘以 10000 |
| `audit_summary_format` | info | 按审核汇总表解析 | 表头有成对的报审/审核/核减金额列，按审核汇总版式解析 |
| `sheet_total_mismatch` | error | 合计对不上 | 明细行之和与该表合计行偏差超过 0.5%：可能漏行或多算了标题/小计行 |
| `measure_sheet_unreconciled` | error | 技术措施表对不上，未计入 | 措施综合单价计算表的清单项（数量 × 综合单价小计）之和与同一单位工程费用表的「施工技术措施项目」相差超过 1 元（没有费用表时与本表合计行比），整张没有计入；这张表上的措施项请人工核对 |
| `summary_detail_mismatch` | error | 汇总表与明细表对不上 | 汇总表只用于勾稽、不计入；两者之和偏差超过 0.5% |
| `summary_only` | info | 只有汇总表 | 工作簿里没有明细表，已按汇总表计入 |
| `cross_sheet_dedup` | info | 跨表重复行已去重 | 不同工作表里编码、名称、金额完全相同的行只计一次 |
| `coverage_partial` | warn | 部分清单表未计入 | 可识别清单表的金额没有全部计入，见各表状态 |
| `coverage_poor` | error | 覆盖率不足 | 可识别清单表的金额计入不到一半，结果不可作为结论 |
| `chapter_coverage_low` | info | 章名覆盖率低 | 来自标准章名表的金额不到 80%，其余归入补充项目/无编码项/非国标编号项 |
| `amounts_identical_suspect` | error | 两侧金额疑似取成同一列 | 匹配行里 95% 以上两侧金额逐分相同，且表头有多组金额列；请确认对比口径 |
| `same_file_two_sides` | info | 两侧是同一份文件 | 表头同时有送审、审定两组金额列，已按两组列分别取数；审核对比表这样选是正确用法 |
| `same_file_sheets_excluded` | error | 同一列金额的表未参与对账 | 这些表没有分送审、审定两组金额列，同一份文件放两侧比出来必然全部一致，已剔除；请为它们分别选择送审文件和审定文件 |
| `all_rows_identical` | warn | 全部一致 | 两份文件的每一行金额逐分相同、核减额为 0；这可能是合法结果，也可能是审定文件选错了 |
| `calc_error_rows` | warn | 行内量×价≠合价 | 已在对应行标记「送审计算错误 / 审定计算错误」；差额可能来自算术错误而不是量价调整 |
| `baseline_rows_invalid` | error | 合同基准行不可用 | 基准行既没有清单编码也没有名称，无法按清单严格对齐；超合同、漏报、合同外新增比对本轮未做 |
| `baseline_file_unparsed` | error | 合同/中标清单未解析出清单行 | 该文件没有参与超合同、漏报、合同外新增比对；请确认选的是合同或中标清单（分部分项计价表） |
| `baseline_coverage_low` | warn | 合同基准覆盖率低 | 送审行里能严格对齐到合同清单的不到一半，本轮不判「合同外新增」（大多是没对上，不是真新增） |
| `baseline_conflicts` | warn | 需要人工指定合同行 | 这些行与合同清单对不准：编码相同但名称或单位不同，或合同清单里有多行可对、分不清对哪一行；按铁律 3 不出金额，列为待人工指定 |
| `files_failed` | error | 部分文件未计入 | 这些文件读不出清单或不是清单表，结果只含其余文件 |
| `file_duplicate` | warn | 重复文件已剔除 | 两份文件内容完全相同（sha256 一致），只计一份 |
| `file_overlap_suspect` | warn | 疑似重复清单 | 两份文件的清单行 90% 以上完全相同；同构楼栋可能确实同清单，未自动剔除，请确认没有重复选 |
| `area_missing` | warn | 未提供建筑面积 | 没有总建筑面积，单方造价与各章单方未计算；请在「指标计算」对话框里填写 |
| `fee_total_unavailable` | info | 没有费用表合计 | 所选文件里没有费用表，只算出清单明细合计，不是总造价；可在「含税总造价」里手填 |
| `fee_total_unreadable` | warn | 费用表合计未采用 | 有费用表，但合计没读到或与各单位工程费用表之和对不上（相差超过 1 元）；卡片上的数是清单明细合计，不是总造价。可在「含税总造价」里手填 |
| `fee_breakdown_unreconciled` | info | 费用构成表未显示 | 有单位工程费用表的六项（分部分项、技术措施、组织措施、其他项目、规费、增值税）相加与该表合计相差超过 1 元，构成表不显示；总造价的取数不受影响 |
| `fee_itemized_mismatch` | warn | 费用表与清单对不上 | 费用表里的分部分项工程费（或施工技术措施项目）与读入的清单合计相差超过 1 元：可能有清单行没读进来，也可能费用表不是按这份清单算的，请核对 |

## 接线层状态码（`status_reason`）

| 码 | 状态 | 含义 |
|---|---|---|
| `items_not_counted` | partial | 有 error 级告警：有表或文件没算进去 |
| `coverage_partial` | partial | 可识别清单表的金额没有全部计入 |
| `coverage_poor` | partial | 计入不到一半，结果不能作为结论 |
| `xls_unsupported` | insufficient | 有 .xls，本机不转换；请另存为 .xlsx |
| `basis_not_found` | insufficient | 表头没有所选口径的金额列；换 `--basis auto` 或 `data.detail.basis_available` 里的口径 |
| `column_ambiguous` | insufficient | 表头有多组金额列分不清；用 `--basis` 指定合同/本期/累计 |
| `same_file_same_columns` | insufficient | 送审、审定选了同一份文件且没有两组金额列 |
| `parse_failed` | insufficient | 读不出清单行、全部无价或可计入文件不到一半；原因在 `data.detail.message` |
